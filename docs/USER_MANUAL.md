## 2. 세금 신고하기 (SPT)

### 2.1 어떤 SPT를 선택해야 하나요?

| SPT 유형 | 대상 | 예시 |
|---------|------|------|
| **1770 SS** | 직장인 1곳, 연소득 6천만 루피아 미만 | 일반 회사원 |
| **1770 S** | 직장인 1곳 이상, 연소득 6천만 루피아 이상 | 고소득 직장인, 부업 있는 직장인 |
| **1770** | 사업자, 자유직업인 | 자영업, 의사, 변호사, 프리랜서 |
| **1771** | 법인 | PT, CV, 협동조합 등 |

### 2.2 SPT 1770 SS 작성 (직장인용 간편)

가장 흔한 경우입니다. 회사에서 받은 **1721-A1** (급여 원천징수 증명서)만 있으면 됩니다.

1. 사이드바 → **연간 신고**
2. **"1770 SS"** 선택
3. 납세자 정보 확인
4. 데이터 입력 방법 선택:
   - **사진 업로드**: 1721-A1 사진/PDF 업로드 → AI가 자동 입력
   - **직접 입력**: 회사명, NPWP, 총급여, 원천징수세액 입력
5. **"SPT 생성"** 클릭
6. 미리보기 확인
7. **"PDF 다운로드"** 또는 **"DJP에 신고"**

### 2.3 SPT 1770 S 작성 (근로소득 상세)

1. 사이드바 → 연간 신고 → **"1770 S"**
2. **기본 데이터** 탭:
   - 과세 연도 선택
   - PTKP 상태 선택 (미혼/기혼/부양가족)
   - 정정 번호 (최초 신고는 0)
3. **기타 소득** 탭 (있는 경우):
   - 은행 이자, 배당금, 로열티, 임대 등
4. **세액 공제** 탭:
   - PPh 22 (수입), PPh 23 (서비스), PPh 25 (분할납부)
5. **"SPT 생성"** 클릭

### 2.4 SPT 1770 작성 (사업소득)

1. 사이드바 → 연간 신고 → **"1770"**
2. **기본 데이터** 탭: 과세 연도, PTKP
3. **사업** 탭:
   - 사업명, KLU 코드 입력
   - 부기 방법 선택: Norma(간편) 또는 Pembukuan(정식)
   - 총매출 입력
   - "사업 추가"로 여러 사업 등록 가능
4. **기타 소득** 탭, **세액 공제** 탭
5. **"SPT 생성"**

> **참고**: 연 매출 48억 루피아 미만이면 UMKM 최종세 0.5%가 적용될 수 있습니다. 시스템이 자동으로 안내합니다.

### 2.5 SPT 1771 작성 (법인)

1. 사이드바 → 연간 신고 → **"1771"**
2. 회사 정보: 법인 형태, KLU 코드
3. **손익계산서** 탭:
   - 매출, 매출원가, 영업비용 항목별 입력
   - 기타 수입 (이자, 배당, 임대)
   - 세전이익 자동 계산
4. **대차대조표** 탭:
   - 자산 (유동/고정/기타)
   - 부채 (유동/장기)
   - 자본 (납입자본, 이익잉여금)
   - **Balance** 확인 (자산 = 부채 + 자본)
5. **세액 공제** 탭
6. **"SPT 생성"**

### 2.6 SPT 미리보기에서 확인할 항목

| 항목 | 확인 사항 |
|------|----------|
| 납세자 정보 | 이름, NPWP, 주소가 정확한지 |
| 소득 금액 | 총소득, 순소득이 맞는지 |
| 세액 계산 | 과세소득(PKP), 세율 적용이 맞는지 |
| 상태 | NIHIL(동일), 미납(추가 납부), 과납(환급) |
| **PDF 다운로드** | 기록 보관용 |

## 3. 사진으로 간편 신고 (SimpleMode)

### 3.1 사용 방법

대시보드 상단의 파란 카드를 클릭합니다.

1. **카드 전체 영역 터치/클릭** → 카메라 또는 파일 선택
2. 촬영 또는 저장된 1721-A1 사진/PDF 선택
3. **AI가 자동으로 읽기** (10~30초 소요)
4. 추출된 데이터 확인:
   - 이름, 회사명, 총급여, 원천징수세액
5. **"네, 데이터가 맞습니다"** 클릭
6. SPT 완성!

### 3.2 좋은 사진 찍는 팁

| 항목 | 권장 |
|------|------|
| 밝기 | 밝은 곳에서 촬영 |
| 기울기 | 문서와 평행하게 |
| 범위 | 전체 문서가 다 보이게 |
| 선명도 | 흔들리지 않게 고정 후 촬영 |
| 형식 | JPG, PNG, PDF 지원 |

### 3.3 데이터가 틀리면?

"다시 촬영" 버튼으로 재시도하거나, 직접 수정할 수 있습니다.

## 4. 월간 세금 납부

### 4.1 월간 납부 현황

사이드바 → **월간 납부**

각 세금 유형별 월간 납부 상태를 확인합니다:

| 탭 | 세금 유형 | 기한 |
|-----|----------|------|
| PPh 21 | 근로소득 원천징수 | 매월 10일 (납부), 20일 (신고) |
| PPh 23 | 서비스/배당 원천징수 | 매월 10일 (납부), 20일 (신고) |
| PPh 25 | 분할 납부 | 매월 15일 (납부), 20일 (신고) |
| PPN | 부가가치세 | 익월 말 |
| PPh Final | UMKM 최종세 | 매월 15일 |

### 4.2 납부 상태

| 상태 | 의미 | 색상 |
|------|------|------|
| 대기 중 | 아직 납부 안 함 | 노란색 |
| 납부 완료 | 정상 납부 | 녹색 |
| 기한 초과 | 기한 경과, 2%/월 가산세 | 빨간색 |

### 4.3 거래 상대방 관리

사이드바 → **거래 상대방**

PPh 23 신고 시 필요한 거래처 정보를 관리합니다:

1. **"추가"** 클릭
2. 정보 입력:
   - 이름, NPWP, 유형 (Vendor/Client/Employee)
   - 주소, 전화, 이메일
   - 특수관계인 여부

> **중요**: 거래 상대방에 NPWP가 없으면 세율이 2배 적용됩니다.

## 5. AI 기능 활용

### 5.1 AI 챗봇

화면 우측 하단의 💬 아이콘을 클릭합니다.

**질문 예시**:
- "PPh 21은 어떻게 계산하나요?"
- "SPT 신고 기한이 언제인가요?"
- "UMKM 0.5% 세율을 적용받으려면?"
- "NPWP가 없으면 세금이 얼마나 더 나오나요?"

챗봇은 설정된 언어로 응답합니다. 인도네시아 세법에 특화되어 있습니다.

### 5.2 절세 분석

사이드바 → **절세 분석**

AI가 귀하의 세금 데이터를 분석하여 합법적 절세 기회를 찾아줍니다:

| 분석 항목 | 예시 |
|----------|------|
| PTKP 최적화 | 부양가족 신고 누락 확인 |
| UMKM 세율 적용 | 0.5% 최종세 적용 가능 여부 |
| 자캇 공제 | 종교 기부금 세금 공제 |
| 연금 공제 | JHT/JP 기여금 공제 활용 |
| 세율 구간 최적화 | 소득 분산으로 낮은 세율 적용 |

### 5.3 세금 캘린더

사이드바 → **세금 캘린더**

모든 세금 마감일이 한눈에 표시됩니다:

| 월 | 주요 마감일 |
|----|-----------|
| 매월 10일 | PPh 21/23 납부 기한 |
| 매월 15일 | PPh 25/Final 납부 기한 |
| 매월 20일 | PPh 21/23/25 신고 기한 |
| 매월 말 | PPN 납부/신고 기한 |
| **3월 31일** | **개인 연간 SPT 신고 기한** |
| **4월 30일** | **법인 연간 SPT 신고 기한** |

> **지연 벌금**: 개인 Rp 100,000 / 법인 Rp 1,000,000

## 6. 세금 계산 도구

사이드바 → **세금 도구**

6가지 계산 도구를 제공합니다:

### 6.1 세금 예측

월급과 PTKP 상태를 입력하면 연간 예상 세금을 계산합니다.

**입력**: 월급 (Rp), PTKP 상태 (TK/0 등)
**결과**: 연간 예상 PPh 21, 실효세율

### 6.2 현금흐름 예측

월 매출과 지출을 입력하면 향후 6개월 현금흐름과 세금 적립금을 예측합니다.

**입력**: 월 매출 (Rp), 월 지출 (Rp)
**결과**: 월별 순이익, 세금 적립 권고액

### 6.3 문서 요약

세금 관련 법규 문서(PDF/이미지)를 업로드하면 AI가 핵심 내용을 요약합니다.

### 6.4 관세 계산기

수입품의 관세, PPN, PPh 22를 계산합니다.

**입력**: CIF(USD), 환율, 관세율(%)
**결과**: Bea Masuk, PPN Impor, PPh 22 (NPWP 유무별)

### 6.5 지방세 계산기

지방세(PBB, BPHTB, 음식점세, 호텔세 등)를 계산합니다.

**입력**: 세금 유형, 과세 기준금액
**결과**: 납부할 지방세액

### 6.6 벤치마킹

귀하의 실효세율을 업종 평균과 비교합니다.

**입력**: 업종, 실효세율(%)
**결과**: 업종 평균 대비 분석

## 7. 문서 관리

사이드바 → **문서**

### 7.1 문서 업로드

1. **"업로드"** 클릭
2. 파일 선택 (PDF, JPG, PNG)
3. 문서 유형 선택:
   - 원천징수 증명서 (1721-A1)
   - 세금계산서 (Faktur Pajak)
   - 영수증
   - 기타
4. AI가 자동으로 분류 및 OCR 처리

### 7.2 OCR 데이터 추출

업로드된 문서에서 AI가 자동으로 데이터를 읽어옵니다:

| 문서 유형 | 추출 데이터 |
|----------|-----------|
| 1721-A1 | 이름, 회사, 총급여, 원천징수세액, PTKP |
| Faktur Pajak | 거래처, 금액, PPN |
| 영수증 | 날짜, 금액, 품목 |

### 7.3 문서 보관

모든 업로드된 문서는 안전하게 저장됩니다:
- 암호화 저장
- 역할 기반 접근 (본인만 조회 가능)
- 감사 로그 기록

## 9. 컨설턴트 찾기

사이드바 → **마켓플레이스**

### 9.1 컨설턴트 검색

세무 전문가를 검색하고 연결할 수 있습니다:

1. 법인명으로 검색
2. 컨설턴트 프로필 확인:
   - 전문 분야
   - 라이선스 보유 여부
   - 활성 고객 수
   - 평점
3. **"연락하기"** 클릭

### 9.2 위임장 (POA) 발급

컨설턴트에게 세금 신고를 위임하려면 위임장(Surat Kuasa)이 필요합니다:

1. 사이드바 → POA 생성
2. 위임 범위 선택:
   - 전체 세금
   - PPh 21만
   - PPN만
   - 연간 SPT만
3. 유효 기간 설정
4. **서명** → 컨설턴트에게 전달
5. 세무사가 서명하면 **ACTIVE** 상태로 변경

### 일반

**Q: AI Pajak은 안전한가요?**
A: 네. 모든 데이터는 암호화되어 저장되며, 플랫폼 관리자도 세금 데이터에 접근할 수 없습니다 (보안 규칙 #1). Supabase의 Row Level Security로 본인 데이터만 조회 가능합니다.

**Q: 모바일에서도 사용할 수 있나요?**
A: 네. 모든 기능이 모바일 브라우저에서 작동합니다. 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

**Q: 비밀번호를 잊었어요.**
A: 로그인 페이지에서 "비밀번호 찾기"를 클릭하면 이메일로 재설정 링크가 전송됩니다.

### SPT 신고

**Q: 1721-A1이 뭔가요? 어디서 받나요?**
A: 회사에서 매년 발급하는 급여 원천징수 증명서입니다. 보통 연초(1~2월)에 인사부(HRD)에서 받을 수 있습니다.

**Q: SPT 신고 기한을 놓치면?**
A: 개인은 Rp 100,000, 법인은 Rp 1,000,000의 벌금이 부과됩니다. 세금 캘린더에서 마감일을 확인하고 알림을 설정해두세요.

**Q: 정정 신고는 어떻게 하나요?**
A: SPT 작성 시 "정정 번호"를 1로 변경하면 됩니다 (최초 신고는 0).

**Q: NIHIL, 미납(Kurang Bayar), 과납(Lebih Bayar)이 뭔가요?**
A:
- **NIHIL**: 세액 = 원천징수, 추가 납부/환급 없음
- **미납(Kurang Bayar)**: 원천징수 < 세액, 추가 납부 필요
- **과납(Lebih Bayar)**: 원천징수 > 세액, 환급 신청 가능

### UMKM/사업자

**Q: UMKM 0.5% 세율은 누가 받을 수 있나요?**
A: 연 매출 48억 루피아 미만인 개인사업자/법인. PP 55/2022에 따라 첫 5억 루피아는 면세입니다. 개인은 7년, PT는 3년, CV는 4년간 적용 가능합니다.

**Q: NPWP가 없으면 세금이 얼마나 더 나오나요?**
A:
- PPh 21: **20% 할증** (예: 세율 5% → 6%)
- PPh 23: **100% 할증** (예: 서비스 2% → 4%)
- PPh 22: **100% 할증** (예: 정부조달 1.5% → 3%)

### 결제

**Q: 어떤 결제 수단을 지원하나요?**
A: BCA, Mandiri, BNI, BRI 은행 이체, GoPay, OVO, DANA, 신용/체크카드, 가상계좌 (Midtrans 통해)

**Q: 환불은 어떻게 하나요?**
A: 고객센터에 문의하시면 관리자가 처리합니다.
