### 1.2. Coretax 전환 — 시장을 뒤흔든 규제 변화

2025년 1월, 인도네시아 국세청(DJP)이 **Coretax** 시스템을 의무 시행했습니다. 42개 기존 세금 규정을 하나로 통합하고(PMK 81/2024), 등록·신고·납부·환급을 하나의 디지털 플랫폼으로 이관하는 것이 목표였습니다.

**그러나 시행 초기에 심각한 혼란이 발생했습니다:**

| 문제 | 영향 |

| 디지털 인증서 접근 불가 | 전자서명 자체 불가능 |
| **세수 30.2% 감소** (2025년 2월 기준) | Coretax 혼란이 주요 원인 |
| 50세 이상 납세자 성공률 | 54%만 시스템 사용 성공 |
| 국회 대응 | Coretax 의무 시행 **연기 요청** |

**이 혼란이 "Coretax를 대신 처리해주는 도구" 수요를 폭발적으로 만들었습니다.** 모든 경쟁사가 Coretax 대응에 바쁜 지금이 신규 진입의 최적 타이밍입니다.

### 2.3. 경쟁사별 심층 분석

#### OnlinePajak — 가장 자금력이 강한 선두주자

- **강점**: Series C IDR 2,430억+ 투자, 무료 세금 신고 + 인보이스/결제로 수익화하는 프리미엄 모델, 급여(Payroll) 통합

#### Klikpajak (Mekari) — 에코시스템의 힘

- **강점**: Mekari Jurnal(회계) + Talenta(HR/급여) + Klikpajak 올인원 통합, ISO 27001 인증, 35,000+ 기업 사용자, DJP 공식 파트너
- **약점**: AI 기능 없음, 세무사 전용 대시보드 부재, Mekari 에코시스템에 종속
- **위협 수준**: 가장 높음 (생태계 lock-in 효과)

#### Pajak.io — 대기업 전문

- **강점**: Host-to-Host DJP 연동으로 대량 처리 최적화, BlueBird/GOTO/Telkom 등 대기업 레퍼런스
- **약점**: 중소기업/개인 접근성 낮음, 셀프서비스 모델 없음
- **위협 수준**: 낮음 (타겟 시장 다름)

#### Pajakku — 원조 PJAP (2005~)

- **강점**: 인도네시아 최초 PJAP, SIP(세금통합시스템)/BIP(비즈니스 인텔리전스) 등 고급 분석 도구, 깊은 DJP 관계

- **위협 수준**: 중간 (다른 세그먼트)

#### HiPajak — 모바일 개인 SPT 전문

- **강점**: 100,000+ 개인 사용자, 모바일 우선, Coretax SPT 가이드 기능, Alibaba GET Challenge 수상
- **약점**: 법인/UMKM 기능 없음, SPT Masa 미지원, 세무사 도구 없음

## 3. AI Pajak의 경쟁 우위 (검증됨)

### 3.1. AI/OCR — 시장에서 유일

> **조사 결과: 어떤 경쟁사도 AI/OCR 기반 자동 데이터 추출을 핵심 기능으로 내세우지 않습니다.**

AI Pajak이 제공하는 것:
- **Form 1721-A1 OCR** — 원천징수영수증 사진/PDF → 모든 항목 자동 입력
- **Faktur Pajak OCR** — 세금계산서 사진 → 공급업체 NPWP, 금액, PPN 자동 분류
- **인보이스 일괄 캡처** — 매입·매출 인보이스 자동 분류 → PPN 신고에 바로 반영
- **세무 최적화 AI** — 이상 거래 탐지, PTKP 자동 추천, 환급 여부 판정

이것이 중요한 이유: 인도네시아 납세자의 가장 큰 불만이 **수작업 데이터 입력**입니다. A1 한 장을 수기로 입력하는 데 평균 10분이 걸리는데, OCR로 30초면 끝납니다. 100명 직원의 PPh21 처리 시 **16시간 절감 효과**.

### 3.2. 세무사 멀티테넌트 — 경쟁사가 약한 영역

| 기능 | 경쟁사 수준 | AI Pajak |
|---|---|---|
| 다중 고객 관리 | 기본 목록 | **RLS 기반 완벽 격리** — 사무소 간 데이터 절대 볼 수 없음 |
| 일괄 PPh21 처리 | 없음 | **Growth 플랜 이상에서 여러 고객 동시 처리** |
| 월 통합 대시보드 | 없음 | **고객 × 신고 유형 교차표**, 미결·완료·기한 한눈에 |
| 팀 관리 | 없음 | **사무소 내 직원 초대·배정·비활성화** |
| 클라이언트별 POA | 기본 | **위임장 유효기간 자동 알림, 만료 시 제출 차단** |
| 고객 확장 한도 | 35명이 일반적 한계 | **Enterprise Tier: 무제한** |

세무사 1명 = 35+ 납세자. **세무사 10곳만 확보하면 자연스럽게 350+ 납세자 포트폴리오**가 형성됩니다.

### 3.3. SPT Masa + Tahunan 통합 — 월에서 연으로 자동 집계

경쟁사 대부분은 월간 신고와 연간 신고를 별도 워크플로우로 처리합니다.

AI Pajak에서는:
1. 매월 PPh21/PPh23/PPN 데이터를 입력하면
2. 연말에 SPT 1771(법인)에 **자동 집계**
3. 재무제표 + 분개장 + 원천세 총괄표가 한 번에 준비

법인 고객의 **연말정산 부담을 90% 감소**시키는 핵심 가치입니다.

## 4. AI Pajak의 경쟁 열위 (솔직한 평가)

### 4.1. PJAP 인증 미보유 — 가장 큰 구조적 약점

모든 주요 경쟁사(OnlinePajak, Klikpajak, Pajakku, Pajak.io)가 DJP 공식 PJAP(전자세금처리대행사)입니다. AI Pajak은 JTC를 통한 간접 처리 방식인데:
- 대기업·공공기관 입찰 시 **자격 미달** 가능
- 고객 신뢰도에 영향 (직접 인증 vs 간접)
- 중장기적으로 **독립 PJAP 취득이 필수**

### 4.2. 시장 인지도 = 0

| 경쟁사 | 시장 존재감 |
|---|---|
| OnlinePajak | Series C IDR 2,430억+ 투자 |
| Klikpajak | 35,000+ 기업 사용자 |
| Pajakku | 2005년부터 20년 운영 |
| HiPajak | 100,000+ 개인 사용자 |
| **AI Pajak** | **실사용자 0명** |

브랜드 인지도와 레퍼런스 고객이 전혀 없는 상태입니다. 초기 10개 세무사 확보가 사활적입니다.

### 4.3. Mekari 에코시스템과의 경쟁

Klikpajak + Jurnal(회계) + Talenta(HR/급여)의 올인원 생태계는 **강력한 lock-in**을 만듭니다.
- 이미 Jurnal 사용 중인 기업 → Klikpajak 무료 또는 저가로 사용 가능
- 전환 비용이 높아 AI Pajak으로 이탈할 동기 약함
- **대응 전략**: Accurate/Zahir 연동 강화로 Mekari가 아닌 회계SW 사용자 흡수

### 4.4. 실사용 검증 부족

- 결제 게이트웨이(PG) 미연결 상태
- 실제 DJP 제출 End-to-End 검증 미완
- Coretax API 실연동 미완
- 수년간 축적된 경쟁사의 DJP 연동 노하우와 엣지 케이스 처리 대비 미숙

## 5. 전략 권장

### 5.1. 어디서 싸울 것인가 — 우선순위 매트릭스

| 전략 | 왜 | 우선순위 | 기간 |

| **UMKM Final Tax 자동화** | 6,400만 UMKM 중 0.5% Final Tax 대상만 겨냥해도 거대. 경쟁사들은 일반과세 기업에 집중 | **최우선** | 3~6개월 |
| **AI/OCR "마법" 데모** | 1721-A1 사진 한 장 → 30초 만에 SPT 완성 = 데모 효과 최대. 유튜브/인스타 바이럴 가능성 | **중요** | 즉시 가능 |

| **PJAP 독립 취득** | 대기업·기관 진입 + 고객 신뢰 확보의 필수 조건 | **중요** | 6~12개월 |
| **개인 SPT 시장** | HiPajak이 무료 + 100K 사용자. 여기서 싸우면 출혈 경쟁. 세무사 확보 후 자연 유입 기대 | **후순위** | 보류 |

### 5.2. 킬러 시나리오 — "세무사를 잡으면 시장이 따라온다"

```
Phase 1: 세무사 10곳 확보 (3개월)
  ├─ AI/OCR 데모로 세무사 관심 유도
  ├─ Growth 플랜 무료 체험 제공 (3개월)
  ├─ 세무사 1곳 = 평균 35명 고객
  └─ 결과: 350+ 납세자 포트폴리오

Phase 2: 납세자 입소문 확산 (3~6개월)
  ├─ 세무사 고객이 AI Pajak 경험 → 추천
  ├─ 고객이 지인에게 추천 → 개인/UMKM 자연 유입
  ├─ UMKM Final Tax 셀프서비스 오픈
  └─ 결과: 1,000+ 납세자

Phase 3: 법인 시장 진입 (6~12개월)
  ├─ PJAP 독립 취득
  ├─ Accurate/Zahir 연동 완성
  ├─ 법인 월신고→연신고 통합 가치 입증
  └─ 결과: 법인 100+ 고객, MRR Rp 150M+
```

### 5.3. 반드시 피해야 할 것

1. **OnlinePajak/Klikpajak과 정면 대결** — 자금력과 사용자 기반에서 이길 수 없음. 그들이 약한 "세무사"와 "AI/OCR" 영역에서 싸울 것
2. **HiPajak과 개인 시장에서 가격 경쟁** — 무료 대비 유료는 설득력이 약함. 개인은 세무사 경유로 자연 유입시킬 것
3. **기능 나열 경쟁** — 경쟁사들은 10년 이상 기능을 쌓았음. "기능이 더 많다"가 아니라 **"AI로 10배 빠르다"**가 메시지여야 함

### 한 줄 정리

> **"AI/OCR + 세무사 멀티테넌트"라는 경쟁사가 없는 조합으로, "세무사 먼저 잡고 → 납세자가 따라오게 하는" B2B2C 전략이 가장 현실적인 승리 경로입니다.**
