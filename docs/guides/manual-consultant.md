## 1. 시작하기

### 1.1 로그인

1. https://aipajak.com 접속
2. JTC에서 발급받은 이메일과 비밀번호 입력
3. 2FA가 활성화된 경우, 인증 코드 입력
4. 로그인 성공 시 대시보드로 이동

> 비밀번호 분실 시 로그인 페이지의 **"비밀번호 찾기"** 링크를 클릭하여 재설정 이메일을 받으세요.

### 1.2 대시보드 이해

로그인 후 대시보드에는 다음 정보가 표시됩니다:

| 영역 | 설명 |
|------|------|
| 담당 고객 현황 | 전체 담당 고객 수, 신규 고객, 활성 고객 통계 |
| 마감일 알림 | 다가오는 세금 신고/납부 기한 (7일 이내 강조 표시) |
| 긴급 작업 | 기한 임박 신고, 미완료 작업 목록 |
| 최근 활동 | 최근 처리한 신고, 문서 업로드, 고객 변경 이력 |
| 월별 신고 현황 | SPT Masa 진행 상태 요약 |

### 1.3 사이드바 메뉴 구조

```

```

### 1.4 언어 설정

## 2. 고객 관리

### 2.1 고객 목록 조회

**경로**: 사이드바 > 고객 관리 > 고객 목록

고객 목록에서 담당 고객 전체를 확인할 수 있습니다.

**필터 옵션**:
- 납세자 유형: 개인 / 법인
- 신고 상태: 진행 중 / 완료 / 미제출
- 기간: 과세 연도 선택
- 검색: 이름, NPWP, 이메일로 검색

**정렬 옵션**:
- 이름 (가나다순 / 역순)
- 최근 활동일
- 신고 마감일

**페이지네이션**: 페이지당 10/25/50건 선택 가능

### 2.2 고객 생성

**경로**: 사이드바 > 고객 관리 > 고객 생성

1. **기본 정보** 입력
   - 성명 (Full Name)
   - 이메일
   - 전화번호
   - 납세자 유형: 개인(INDIVIDUAL) / 법인(COMPANY)

2. **세금 정보** 입력
   - NPWP (납세자 번호)
   - NIK (주민번호, 개인만)
   - 법인의 경우: 회사명, 사업자 등록 번호

3. **"저장"** 클릭

> 고객 생성 시 해당 고객에게 초대 이메일이 발송됩니다. 고객은 자신의 계정으로 로그인하여 신고 진행 상황을 확인할 수 있습니다.

### 2.3 고객 상세 정보

고객 목록에서 고객을 클릭하면 상세 화면으로 이동합니다.

**탭 구성**:

| 탭 | 내용 |
|----|------|
| 프로필 | 기본 정보 조회 및 수정 (이름, 연락처, NPWP, 주소 등) |
| 신고 | 해당 고객의 전체 신고 이력 (SPT Masa + SPT Tahunan) |
| POA | 위임장 현황 (유효/만료/진행중) |
| 활동 | 감사 로그 — 누가 언제 어떤 작업을 수행했는지 기록 |

### 2.4 고객 메모

고객 상세 > 프로필 탭에서 내부 메모를 작성할 수 있습니다.

- 메모는 JTC 내부 직원만 열람 가능 (고객에게 노출되지 않음)
- 고객 특이사항, 주의사항, 상담 내역 등을 기록
- 메모 작성/수정 시 작성자와 시간이 자동 기록

### 2.5 컨설턴트 할당/해제 [세무사 전용]

세무사는 고객에게 담당 컨설턴트를 할당하거나 해제할 수 있습니다.

1. 고객 상세 > 프로필 탭
2. **"담당 컨설턴트"** 섹션에서 **"할당"** 또는 **"변경"** 클릭
3. JTC 소속 컨설턴트 목록에서 선택
4. 확인

> 컨설턴트 변경 시 기존 담당자에게 알림이 발송됩니다.

## 3. 세금 신고 작업

### 3.1 신고 작업 흐름 (5단계 마법사)

**경로**: 사이드바 > 세금 관리 > 새 신고 생성

세금 신고는 5단계 마법사(Wizard)를 통해 진행됩니다:

```
1. 고객 선택 → 2. 소득 데이터 → 3. 공제 항목 → 4. 서류 첨부 → 5. 검토 및 제출
```

#### Step 1: 고객 선택

- 담당 고객 목록에서 신고 대상 고객 선택
- 과세 연도/월 선택
- 신고 유형 선택 (PPh21, PPh23, PPh Final, PPN, SPT Tahunan)

#### Step 2: 소득 데이터 입력

신고 유형에 따라 입력 항목이 다릅니다:

| 신고 유형 | 입력 항목 |
|----------|----------|
| PPh21 | 총급여, 수당, 상여금 |
| PPh23 | 서비스 소득, 로열티, 배당, 이자 |
| PPh Final | 임대 소득, 건설 소득 |
| PPN | 매출액, 서비스 매출 |
| 공통 | 기타 소득, 설명 |

- OCR로 자동 입력된 데이터가 있으면 미리 채워져 표시
- 수동으로 수정 가능

#### Step 3: 공제 항목

| 공제 유형 | 입력 항목 |
|----------|----------|
| PPh21 | 직무수당(Biaya Jabatan), 연금 보험료, PTKP 상태 |
| PPN | 매입세액(Input Tax) |
| 공통 | 기타 공제, 공제 비고 |

**PTKP 상태 선택**:
- TK/0 ~ TK/3 (미혼, 부양가족 0~3명)
- K/0 ~ K/3 (기혼, 부양가족 0~3명)

#### Step 4: 서류 첨부

- 관련 증빙 서류 업로드 (PDF, JPG, PNG)
- 이미 업로드된 문서가 있으면 기존 문서 연결 가능
- OCR 처리된 문서에서 자동 추출된 데이터 확인

#### Step 5: 검토 및 제출

- 입력 데이터 전체 요약 확인
- 세금 계산 결과 검토
- **컨설턴트**: "임시 저장" 또는 "제출 요청" (세무사에게 최종 제출 요청)
- **세무사**: "임시 저장" 또는 **"최종 제출"** (DJP에 직접 제출)

> **중요**: 최종 제출(DJP 전송)은 세무사(TAX_ADVISOR_JTC)만 가능합니다. 컨설턴트는 데이터 준비 후 세무사에게 제출을 요청합니다.

### 3.2 SPT Tahunan (연간 신고)

**경로**: 사이드바 > 세금 관리 > SPT Tahunan

연간 개인소득세 신고를 위한 SPT 양식:

| SPT 유형 | 대상 |
|---------|------|
| 1770 SS | 직장인 1곳, 연소득 6천만 IDR 미만 |
| 1770 S | 직장인 1곳 이상, 연소득 6천만 IDR 이상 |
| 1770 | 사업자, 자유직업인, 프리랜서 |
| 1771 | 법인 (현재 비활성화) |

각 양식 선택 후 동일한 5단계 마법사를 통해 작성합니다.

### 3.3 신고 이력 관리

**경로**: 사이드바 > 신고 이력

- 전체 신고 이력을 날짜, 고객, 유형, 상태별로 조회
- 신고 상세에서 PDF 다운로드, 수정 이력 확인
- 상태: 초안(Draft) / 검토중(In Review) / 제출됨(Submitted) / 완료(Completed) / 실패(Failed)

## 4. 월별 신고 (SPT Masa)

### 4.1 월별 대시보드

**경로**: 사이드바 > 세금 관리 > 월별 대시보드

월별 세금 신고 현황을 한눈에 파악할 수 있는 대시보드입니다.

| 항목 | 설명 |
|------|------|
| 월 선택 | 해당 월의 전체 신고 현황 조회 |
| 세금 유형별 현황 | PPh21, PPh23, PPh4(2), PPN 각각의 진행 상태 |
| 마감일 카운트다운 | 각 세금 유형별 신고/납부 기한까지 남은 일수 |
| 고객별 진행률 | 담당 고객별 신고 완료율 |

### 4.2 지원하는 월별 세금 유형

| 세금 유형 | 설명 | 신고 기한 |
|----------|------|----------|
| **PPh 21** | 급여 원천징수세 | 매월 20일 |
| **PPh 23** | 서비스/로열티/이자 원천징수세 | 매월 20일 |
| **PPh 4(2)** | 최종세 (임대, 건설 등) | 매월 20일 |
| **PPN** | 부가가치세 | 매월 말일 |

### 4.3 월별 신고 작성

**경로**: 사이드바 > 세금 관리 > SPT Masa

1. 고객 선택
2. 과세 월 선택
3. 세금 유형 선택 (PPh21/23/4(2)/PPN)
4. 소득/매출 데이터 입력
5. 세액 자동 계산 확인
6. 서류 첨부
7. 검토 후 저장 또는 제출 요청

### 4.4 월별 납부 관리

신고 후 납부가 필요한 경우:
1. e-Billing 코드 생성
2. 납부 증빙 업로드
3. 납부 확인 처리

## 5. PPh21 대량 처리 (급여대장)

### 5.1 개요

여러 직원의 PPh21을 한 번에 처리할 수 있는 대량 처리 기능입니다.

**경로**: 사이드바 > 세금 관리 > PPh21 대량 처리

### 5.2 사용 방법

1. **고객(법인) 선택** — PPh21 대량 처리 대상 법인 선택
2. **급여대장 업로드**
   - 엑셀(XLSX) 또는 CSV 형식
   - 필수 컬럼: 직원명, NPWP/NIK, 총급여, 수당, 상여금, PTKP 상태
3. **데이터 검증**
   - 시스템이 자동으로 데이터 형식 검증
   - 오류가 있는 행은 빨간색으로 표시
   - 오류 수정 후 재검증
4. **일괄 계산**
   - 모든 직원의 PPh21 세액 자동 계산
   - 계산 결과 미리보기 (직원별 세액 명세)
5. **검토 및 확인**
   - 전체 합계 확인
   - 개별 직원 세액 검토
6. **제출** — 검토 완료 후 저장 또는 제출 요청

### 5.3 급여대장 템플릿

시스템에서 제공하는 표준 템플릿을 다운로드하여 사용하세요.

| 컬럼 | 필수 | 설명 |
|------|------|------|
| employee_name | O | 직원 성명 |
| npwp | O | 납세자 번호 |
| nik | O | 주민번호 |
| gross_salary | O | 총급여 (IDR) |
| allowances | | 수당 합계 (IDR) |
| bonus | | 상여금 (IDR) |
| ptkp_status | O | TK/0, K/1 등 |
| pension_contribution | | 연금 보험료 (IDR) |

## 6. 문서 및 OCR 활용

### 6.1 문서 업로드

**경로**: 사이드바 > 문서 관리

지원 형식: PDF, JPG, PNG (최대 10MB)

1. **"업로드"** 버튼 클릭
2. 파일 선택 또는 드래그 앤 드롭
3. 고객 선택 (문서를 연결할 고객)
4. 문서 유형 선택 (급여명세서, 세금계산서, 증빙 서류 등)
5. 업로드 완료

### 6.2 OCR 자동 인식

업로드된 문서에 대해 AI OCR이 자동으로 작동합니다:

- **급여명세서 (1721-A1)**: 회사명, NPWP, 총급여, 원천징수세액 자동 추출
- **세금계산서 (Faktur Pajak)**: 거래 상대방, 세액, 날짜 자동 추출
- **기타 증빙**: 금액, 날짜, 거래 내용 추출 시도

OCR 결과는 자동으로 해당 고객의 신고 데이터에 연결됩니다.

### 6.3 문서 분류

업로드된 문서는 AI가 자동 분류합니다:
- 소득 증빙
- 비용 증빙
- 세금 납부 증빙
- 사업자 서류
- 기타

잘못 분류된 경우 수동으로 변경 가능합니다.

### 6.4 문서에서 신고 데이터 연결

OCR로 추출된 데이터를 신고 작성 시 활용하는 방법:

1. 문서 관리에서 OCR 완료된 문서 확인
2. **"신고에 연결"** 클릭
3. 대상 신고 선택
4. 추출된 데이터가 신고 양식에 자동 반영

## 7. 리포트 및 분석

### 7.1 클라이언트 리포트

**경로**: 사이드바 > 리포트

담당 고객의 세무 현황을 종합적으로 볼 수 있는 리포트:

| 리포트 유형 | 내용 |
|-----------|------|
| 고객별 신고 현황 | 고객별 신고 완료/미완료 현황 |
| 세금 유형별 현황 | PPh21/23/4(2)/PPN별 처리 현황 |

## 8. POA 관리 (위임장)

### 8.1 POA란?

POA (Power of Attorney / Surat Kuasa)는 세무사가 고객을 대리하여 세금 신고를 수행할 수 있는 법적 위임장입니다. 세금 신고의 최종 제출을 위해 유효한 POA가 반드시 필요합니다.

**경로**: 사이드바 > POA 관리

### 8.2 POA 생성

1. **"새 POA 생성"** 클릭
2. 위임인(고객) 선택
3. POA 범위 설정:

| 설정 항목 | 설명 |
|----------|------|
| 세금 유형 | PPh21, PPh23, PPN 등 위임 범위 |
| 유효 기간 | 시작일 ~ 종료일 |
| 과세 연도/월 | 대상 기간 |
| 위임 범위 | 신고 대리, 세무 상담, 이의 제기 등 |

4. **"생성"** 클릭 → POA 문서가 생성됨

### 8.3 POA 서명 및 승인 [세무사 전용]

세무사만 POA에 서명하고 승인할 수 있습니다:

1. POA 관리 > 서명 대기 목록 확인
2. POA 내용 검토
3. **"서명"** 클릭
4. 전자 서명 또는 인증 수행
5. POA 상태가 **"유효(Active)"** 로 변경

**POA 상태**:
- 초안(Draft) — 생성되었으나 서명 전
- 대기중(Pending) — 서명 요청됨
- 유효(Active) — 서명 완료, 사용 가능
- 만료(Expired) — 유효 기간 초과
- 해지(Revoked) — 취소됨

### 8.4 POA와 신고 제출의 관계

```
POA 유효 확인 → 세무사가 최종 제출 가능
POA 미유효 → 최종 제출 차단 (시스템에서 자동 검증)
```

> 시스템은 신고 제출 시 `requireValidPOA()` 미들웨어를 통해 유효한 POA가 있는지 자동 검증합니다. POA가 없거나 만료된 경우 제출이 차단됩니다.

## 10. FAQ

### 일반

**Q: 컨설턴트와 세무사의 차이가 무엇인가요?**
A: 컨설턴트는 고객 관리와 세금 데이터 준비를 담당합니다. 세무사는 컨설턴트의 모든 권한에 더해 **세금 신고 최종 제출**, **POA 서명/승인**, **컨설턴트 할당/해제** 권한이 추가됩니다.

**Q: 여러 고객의 신고를 동시에 진행할 수 있나요?**
A: 네, 각 고객별로 별도의 신고 세션이 관리됩니다. 한 고객의 신고를 임시 저장하고 다른 고객의 작업으로 전환할 수 있습니다.

**Q: 다른 컨설턴트가 담당하는 고객의 데이터를 볼 수 있나요?**
A: 아니요. 본인에게 할당된 고객의 데이터만 접근할 수 있습니다. 이는 Supabase RLS(Row Level Security)로 시스템 수준에서 강제됩니다.

### 신고 관련

**Q: 신고 제출 후 수정이 가능한가요?**
A: 제출 전에는 자유롭게 수정 가능합니다. 제출 후에는 정정 신고(Pembetulan)로 처리해야 합니다. 정정 신고 시 정정 번호가 증가합니다.

**Q: PPh21 대량 처리에서 오류가 발생하면 어떻게 하나요?**
A: 오류가 있는 행은 빨간색으로 표시됩니다. 해당 행을 수정하거나, 엑셀 파일을 수정 후 다시 업로드할 수 있습니다. 오류가 있는 상태에서는 제출이 차단됩니다.

**Q: OCR 인식 결과가 정확하지 않을 때는?**
A: OCR 결과는 자동 추출된 것이므로 반드시 검토가 필요합니다. 신고 마법사의 소득 데이터 단계에서 수동으로 수정할 수 있습니다.

### 보안 관련

**Q: PLATFORM_ADMIN이 고객 세금 데이터에 접근할 수 있나요?**
A: 아니요. 플랫폼 관리자는 세금 데이터에 절대 접근할 수 없습니다. 이는 시스템의 5대 보안 규칙 중 하나입니다.

**Q: 모든 작업은 기록되나요?**
A: 네. 모든 데이터 쓰기 작업은 감사 로그(Audit Trail)에 기록됩니다. 누가, 언제, 어떤 작업을 수행했는지 추적할 수 있습니다.
