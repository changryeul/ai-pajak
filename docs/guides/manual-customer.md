## 1. 시작하기

### 1.1 회원가입

1. https://aipajak.com 에 접속합니다.
2. 우측 상단의 **"Daftar"(회원가입)** 버튼을 클릭합니다.
3. 다음 정보를 입력합니다:
   - **이름** (Nama Lengkap)
   - **이메일** (Email)
   - **전화번호** (No. Telepon)
   - **비밀번호** (Password) — 8자 이상
   - **비밀번호 확인** (Konfirmasi Password)
4. **"Daftar"** 버튼을 클릭하여 가입을 완료합니다.
5. 입력한 이메일로 인증 메일이 발송됩니다. 메일 내 인증 링크를 클릭하여 계정을 활성화합니다.

### 1.2 온보딩

회원가입 후 최초 로그인 시 **온보딩 마법사**가 표시됩니다.

1. **프로필 설정**: NPWP(납세자 번호), 납세자 유형(개인/법인), 주소 등 기본 정보를 입력합니다.
2. **서비스 선택**: 필요한 세금 신고 유형을 선택합니다.
3. **위임장 작성**: Jakarta Tax Consulting(JTC)에 대한 위임장(POA)을 생성합니다.
4. **완료**: 대시보드로 이동합니다.

### 1.3 대시보드 이해

로그인 후 표시되는 대시보드에서 다음 정보를 한눈에 확인할 수 있습니다:

- **신고 현황 요약** (Filing Summary): 전체 신고 건수, 진행 중, 완료된 건수
- **마감일 캘린더** (Deadline Calendar): 다가오는 세금 신고 마감일
- **긴급 작업** (Urgent Actions): 즉시 처리가 필요한 항목
- **POA 상태** (POA Status): 위임장 유효 여부
- **컴플라이언스 점수** (Compliance Score): 세금 준수 현황 점수
- **시작 가이드** (Getting Started Guide): 최초 사용자를 위한 단계별 안내

**주요 메뉴 구성**:

| 메뉴 | 설명 |
|------|------|
| 대시보드 | 전체 현황 요약 |
| 세금 신고 | SPT Tahunan(연간) / SPT Masa(월별) 신고 |
| 문서 | 서류 업로드 및 관리 |
| 신고 이력 | 제출된 신고 현황 및 BPE 다운로드 |
| 위임장(POA) | 위임장 생성 및 관리 |
| 결제 | 구독 및 인보이스 관리 |
| 리포트 | 세금 요약, 신고 이력, 결제 이력 리포트 |
| 설정 | 프로필, 보안, 알림, 언어 설정 |

## 2. 세금 신고하기

### 2.1 연간 신고 (SPT Tahunan)

#### SPT 유형 선택

1. **대시보드 > 세금 신고 > SPT Tahunan** 메뉴를 클릭합니다.
2. 소득 유형에 맞는 SPT 양식을 선택합니다:

| 양식 | 대상 | 소득 한도 |
|------|------|-----------|
| **SPT 1770 SS** | 단일 고용주 근로소득자 | 연 Rp 60,000,000 이하 |
| **SPT 1770 S** | 복수 소득원 근로소득자 | 연 Rp 60,000,000 초과 |
| **SPT 1770** | 사업소득 / 자유직업소득자 | 제한 없음 |

3. 선택한 양식의 **"Mulai"(시작)** 버튼을 클릭합니다.

#### SPT 1770 SS 작성 (간편 양식)

1. **소득 정보 입력**: 연간 총 급여(Bruto), 세금 공제액을 입력합니다.
2. **공제 항목 확인**: PTKP(비과세 기본공제) 상태(TK/0, K/1 등)를 선택합니다.
3. **서류 첨부**: Form 1721-A1 등 관련 서류를 업로드합니다.
4. **검토 및 제출**: 계산 결과를 확인하고 **"Kirim"(제출)** 버튼을 클릭합니다.

#### SPT 1770 S 작성 (표준 양식)

1. **소득 정보 입력**: 근로소득, 기타소득(이자, 배당, 임대 등)을 항목별로 입력합니다.
2. **공제 항목 입력**: 비야야 자바탄(직무비용), 연금 보험료, PTKP 상태를 설정합니다.
3. **서류 첨부**: 1721-A1, 이자/배당 증빙 등 관련 서류를 업로드합니다.
4. **세액 자동 계산**: 시스템이 누진세율에 따라 세액을 자동으로 계산합니다.
5. **검토 및 제출**: 모든 항목을 확인하고 제출합니다.

#### SPT 1770 작성 (사업소득 양식)

1. **사업 소득 입력**: 매출, 비용, 순이익을 입력합니다.
2. **기타 소득 입력**: 근로소득, 자본소득 등 추가 소득을 입력합니다.
3. **공제 항목 입력**: 사업 경비, PTKP 등을 입력합니다.
4. **서류 첨부**: 재무제표, 거래 증빙 등을 업로드합니다.
5. **세액 계산 및 검토**: AI가 최적 절세 방안을 제안합니다.
6. **제출**: 최종 검토 후 제출합니다.

#### 신고 마법사 진행 단계

모든 SPT Tahunan 양식은 다음 5단계 마법사를 통해 진행됩니다:

| 단계 | 이름 | 설명 |
|------|------|------|
| 1 | 고객 선택 | 본인 확인 (자동 선택) |
| 2 | 소득 데이터 | 소득 항목 입력 |
| 3 | 공제 항목 | 공제 및 감면 입력 |
| 4 | 서류 첨부 | 증빙 서류 업로드 |
| 5 | 검토 및 제출 | 최종 확인 및 제출 |

각 단계에서 **"Selanjutnya"(다음)** / **"Sebelumnya"(이전)** 버튼으로 이동할 수 있습니다. 모든 필수 항목이 입력되어야 다음 단계로 진행됩니다.

### 2.2 월별 신고 (SPT Masa)

1. **대시보드 > 세금 신고 > SPT Masa** 메뉴를 클릭합니다.
2. 신고할 세금 유형을 선택합니다:
   - **PPh 21**: 근로소득세 (급여 원천징수)
   - **PPh 23/26**: 서비스, 이자, 배당, 로열티 원천징수
   - **PPN**: 부가가치세
3. 해당 월(Masa Pajak)을 선택합니다.
4. 거래 내역을 입력하거나 CSV 템플릿을 다운로드하여 대량 입력합니다.
5. e-Bupot(전자 원천징수 영수증)을 생성합니다.
6. 계산 결과를 확인하고 **신고서를 제출**합니다.

### 2.3 신고 후 진행 상태 확인

제출된 신고는 다음 워크플로를 거칩니다:

```
제출 완료(PENDING) → 데이터 검토(DATA_REVIEW) → 승인 대기(PENDING_APPROVAL) 
→ 승인(APPROVED) → e-Billing 생성 → 납부 대기 → 납부 확인 
→ DJP 제출 → BPE 발급 → 완료(COMPLETED)
```

**대시보드 > 신고 이력**에서 각 단계의 진행 상태를 실시간으로 확인할 수 있습니다.

### 2.4 BPE 다운로드

1. **대시보드 > 신고 이력** 메뉴를 클릭합니다.
2. 상태가 **"COMPLETED"**인 신고 건을 클릭합니다.
3. **"BPE 다운로드"** 버튼을 클릭하여 전자접수증(BPE)을 PDF로 다운로드합니다.

## 3. 문서 관리

### 3.1 서류 업로드

1. **대시보드 > 문서** 메뉴를 클릭합니다.
2. 우측 상단의 **"Upload Baru"(새 업로드)** 버튼을 클릭합니다.
3. 업로드 대화상자에서 파일을 드래그 앤 드롭하거나, 클릭하여 파일을 선택합니다.
4. 지원 형식: PDF, JPG, PNG (최대 10MB)
5. 업로드가 완료되면 AI OCR이 자동으로 서류를 분석하고 분류합니다.

### 3.2 AI OCR 자동 분류

업로드된 서류는 AI가 자동으로 다음을 수행합니다:

- **서류 유형 인식**: Form 1721-A1, Bukti Potong, 영수증, 재무제표 등
- **핵심 데이터 추출**: 금액, 날짜, NPWP, 납세자 정보 등
- **세금 신고 연결**: 추출된 데이터를 해당 세금 신고서에 자동 반영

분류 결과는 각 문서의 상세 페이지에서 확인하고 수정할 수 있습니다.

### 3.3 문서 상태

| 상태 | 설명 |
|------|------|
| **Pending** | 업로드 후 처리 대기 중 |
| **Uploaded** | 업로드 완료, OCR 처리 전 |
| **Verified** | AI 분석 완료, 데이터 검증됨 |
| **Rejected** | 판독 불가 또는 형식 오류 |

### 3.4 문서 다운로드

1. **대시보드 > 문서** 메뉴에서 원하는 문서를 클릭합니다.
2. 문서 상세 페이지에서 **"Download"** 버튼을 클릭합니다.
3. 원본 파일 또는 AI가 생성한 분석 결과를 다운로드할 수 있습니다.

## 4. 위임장(POA) 관리

위임장(Surat Kuasa / Power of Attorney)은 Jakarta Tax Consulting(JTC)이 귀하를 대리하여 세금 신고를 진행하기 위해 필요합니다.

### 4.1 위임장 생성

1. **대시보드 > 위임장(POA)** 메뉴를 클릭합니다.
2. **"Buat POA Baru"(새 위임장 생성)** 버튼을 클릭합니다.
3. 다음 정보를 설정합니다:
   - **위임 범위** (Scope): 전체 세금 유형 / PPh21 전용 / PPh23 전용 / PPN 전용
   - **유효 시작일** (Valid From): 위임 시작일
   - **유효 종료일** (Valid To): 위임 종료일 (기본 1년)
   - **비고** (Notes): 추가 사항 (선택)
4. **"Kirim"(제출)** 버튼을 클릭합니다.
5. 위임장이 **DRAFT** 상태로 생성됩니다.

### 4.2 위임장 서명

1. **대시보드 > 위임장(POA)** 메뉴에서 해당 위임장을 클릭합니다.
2. 위임장 내용을 확인합니다.
3. 서명 문서를 업로드하거나 전자 서명을 진행합니다.
4. 서명이 완료되면 상태가 **ACTIVE**로 변경됩니다.

### 4.3 위임장 상태

| 상태 | 설명 |
|------|------|
| **DRAFT** | 초안 작성됨, 서명 대기 |
| **ACTIVE** | 유효한 위임장, 세금 신고 진행 가능 |
| **EXPIRED** | 유효기간 만료 |
| **REVOKED** | 취소됨 |

> **참고**: 유효한 위임장(ACTIVE)이 없으면 JTC가 귀하의 세금 신고를 대리할 수 없습니다. 대시보드의 POA 상태 위젯에서 만료 예정 알림을 확인하세요.

## 5. 결제 및 구독

### 5.1 구독 플랜 확인

1. **대시보드 > 결제** 메뉴를 클릭합니다.
2. 현재 구독 플랜, 사용량, 다음 결제일을 확인합니다.

### 5.2 플랜 변경

1. **대시보드 > 결제** 화면에서 **"Ubah Paket"(플랜 변경)** 버튼을 클릭합니다.
2. **대시보드 > 결제 > 플랜** 페이지에서 원하는 플랜을 선택합니다.
3. 결제 정보를 입력하고 구독을 완료합니다.
4. Midtrans 결제 시스템을 통해 안전하게 처리됩니다.

### 5.3 인보이스 확인

1. **대시보드 > 결제 > 인보이스** 메뉴를 클릭합니다.
2. 발행된 인보이스 목록을 확인합니다.
3. 각 인보이스를 클릭하여 상세 내용을 보거나 PDF로 다운로드합니다.

### 5.4 결제 이력

결제 대시보드 하단에서 최근 5건의 인보이스를 확인할 수 있습니다. 전체 이력은 **리포트 > 결제 이력 리포트**에서 조회합니다.

## 6. 리포트 확인

### 6.1 리포트 유형

1. **대시보드 > 리포트** 메뉴를 클릭합니다.
2. 조회할 연도를 선택합니다 (최근 5년 내).
3. 원하는 리포트 유형을 선택합니다:

| 리포트 | 설명 |
|--------|------|
| **세금 요약** (Tax Summary) | 해당 기간의 세금 신고 및 납부 요약 |
| **신고 이력** (Filing History) | 전체 세금 신고 목록 및 상태 |
| **결제 이력** (Payment History) | 세금 납부 및 구독 결제 기록 |
| **연간 요약** (Annual Summary) | SPT Tahunan 준비를 위한 종합 연간 보고서 |

4. **"Generate"** 버튼을 클릭하여 리포트를 생성합니다.
5. 생성된 리포트를 화면에서 확인하거나 다운로드합니다.

### 6.2 연간 비교 (Multi-Year Comparison)

리포트 페이지 하단에서 여러 해의 세금 데이터를 비교하는 차트를 확인할 수 있습니다. 전년 대비 소득, 세액, 공제 항목의 변화 추이를 시각적으로 파악할 수 있습니다.

## 7. 보안 설정

### 7.1 프로필 수정

1. **대시보드 > 설정** 메뉴를 클릭합니다.
2. **"Profil"(프로필)** 탭을 선택합니다.
3. 이름, 전화번호, NPWP 등의 정보를 수정합니다.
4. **"Simpan"(저장)** 버튼을 클릭합니다.

### 7.2 비밀번호 변경

1. **대시보드 > 설정** 메뉴를 클릭합니다.
2. **"Keamanan"(보안)** 탭을 선택합니다.
3. 현재 비밀번호를 입력합니다.
4. 새 비밀번호를 입력합니다 (8자 이상, 영문+숫자+특수문자 권장).
5. 새 비밀번호를 한 번 더 입력하여 확인합니다.
6. **"Ubah Password"(비밀번호 변경)** 버튼을 클릭합니다.

### 7.3 2단계 인증 (2FA) 활성화

1. **대시보드 > 설정 > 보안** 탭을 선택합니다.
2. **"Aktifkan 2FA"(2FA 활성화)** 버튼을 클릭합니다.
3. Google Authenticator, Authy 등 TOTP 인증 앱으로 QR 코드를 스캔합니다.
4. 인증 앱에 표시된 6자리 코드를 입력하여 설정을 완료합니다.
5. **백업 코드**를 안전한 곳에 저장합니다 (인증 앱 분실 시 사용).

> **권장**: 계정 보안을 위해 2FA 활성화를 강력히 권장합니다.

### 7.4 로그인 이력 확인

1. **대시보드 > 설정 > 보안** 탭을 선택합니다.
2. 하단의 **로그인 이력** 섹션에서 최근 접속 기록을 확인합니다:
   - 접속 시간
   - IP 주소
   - 기기 정보
3. 의심스러운 접속이 있을 경우 즉시 비밀번호를 변경하세요.

### 7.5 알림 설정

1. **대시보드 > 설정** 메뉴를 클릭합니다.
2. **"Notifikasi"(알림)** 탭을 선택합니다.
3. 다음 알림 항목을 개별적으로 활성화/비활성화할 수 있습니다:
   - **이메일 알림**: 전체 이메일 알림 켜기/끄기
   - **마감일 알림**: 세금 신고 마감일 리마인더
   - **결제 알림**: 구독 결제 및 인보이스 알림
   - **마케팅 이메일**: 프로모션 및 업데이트 소식
4. **"Simpan"(저장)** 버튼을 클릭합니다.

### 7.6 언어 설정

1. **대시보드 > 설정** 메뉴를 클릭합니다.
2. **"Bahasa"(언어)** 탭을 선택합니다.
3. 다음 5개 언어 중 선택합니다:
   - **Bahasa Indonesia** (기본값)
   - **English**
   - **한국어**
   - **日本語**
   - **中文**
4. 선택 즉시 인터페이스 언어가 변경됩니다.

## 8. FAQ

### Q1. 어떤 SPT 양식을 선택해야 하나요?

- **연간 급여소득만 있고, Rp 60,000,000 이하** → SPT 1770 SS
- **급여 + 기타소득이 있거나, Rp 60,000,000 초과** → SPT 1770 S
- **사업소득 또는 자유직업소득이 있음** → SPT 1770

### Q2. 서류를 잘못 업로드했습니다. 어떻게 하나요?

**대시보드 > 문서**에서 해당 문서를 선택하고 삭제한 후, 올바른 서류를 다시 업로드하세요. 이미 신고서에 반영된 경우 해당 신고서를 수정해야 합니다.

### Q3. 위임장(POA)이 만료되면 어떻게 되나요?

POA가 만료되면 JTC가 세금 신고를 대리할 수 없습니다. 대시보드에 만료 알림이 표시되며, 새로운 위임장을 생성해야 합니다.

### Q4. 신고서 제출 후 수정할 수 있나요?

신고서가 **PENDING** 또는 **DATA_REVIEW** 상태일 때는 수정이 가능합니다. **APPROVED** 이후 단계에서는 JTC 컨설턴트에게 문의하세요.

### Q5. 결제 수단은 무엇이 지원되나요?

Midtrans 결제 시스템을 통해 다음 수단을 지원합니다:
- 신용카드 / 체크카드
- 은행 이체 (Virtual Account)
- 전자 지갑 (GoPay, OVO, DANA 등)

### Q6. AI OCR이 서류를 잘못 인식했습니다.

AI 분류 결과는 문서 상세 페이지에서 수동으로 수정할 수 있습니다. 인식률 개선을 위해 선명한 스캔본 또는 원본 PDF를 업로드하는 것을 권장합니다.

### Q7. 2FA 인증 앱을 분실했습니다.

가입 시 제공된 **백업 코드**를 사용하여 로그인한 후 2FA를 재설정하세요. 백업 코드도 분실한 경우 support@aipajak.com 으로 문의하세요.

### Q8. 지원되는 언어는 무엇인가요?

인도네시아어(기본), 영어, 한국어, 일본어, 중국어 총 5개 언어를 지원합니다. **설정 > 언어** 탭에서 변경할 수 있습니다.

### Q9. 세금 캘린더는 어디서 확인하나요?

**대시보드 > 세금 신고 > 세금 캘린더** 메뉴에서 월별/연간 세금 마감일을 확인할 수 있습니다. 대시보드의 마감일 캘린더 위젯에서도 가까운 마감일을 표시합니다.

### Q10. 도움이 필요할 때 어디로 연락하나요?

- **플랫폼 내 도움말**: 대시보드 > 도움말 메뉴
- **이메일**: support@aipajak.com
- **AI 챗봇**: 대시보드 > 채팅 메뉴에서 AI 상담을 이용할 수 있습니다.
