# 법인 납세자 매뉴얼

> **대상**: 인도네시아에서 사업을 운영하며 매월 세금 신고가 필요한 **법인 고객사** 담당자 (재무·경리·대표)
>
> **언어**: 이 매뉴얼은 한국인 오너·재무 담당자를 위한 한국어 가이드입니다. 화면 용어는 인도네시아어/영어가 섞여 있으므로, 본 문서의 "[인도네시아어]" 표기를 따라가시면 됩니다.

## 1. AI Pajak이 무엇을 해 주는가

AI Pajak 은 **MonoFlip 이 운영하는 인도네시아 세무 자동화 플랫폼** 입니다. 법인 고객이 자료를 입력·업로드하면 **Jakarta Tax Consulting (JTC) 소속 세무사·상담원이 대신 세무신고를 처리** 합니다 (Assisted DIY Filing 모델). 법인 고객은 이 시스템에서 다음을 한 곳에서 처리합니다.

- 매월 원천세(PPh21/23/4(2))와 부가세(PPN) 신고
- 급여 계산서(Payslip) 자동 생성 및 BPJS 계산
- 증빙/인보이스 OCR 업로드
- Accurate, Mekari Jurnal 같은 회계 소프트웨어 연동
- 결제(Midtrans) → DJP e-Billing 자동화
- 연간 SPT 1771(법인) 준비

실제 신고 제출과 최종 검수는 **JTC 세무사**와 **운영팀**이 백오피스에서 처리합니다. 고객은 데이터 입력과 결재 확인만 하면 됩니다.

## 2. 가입과 첫 로그인

### 2.1. 회원가입
1. `https://ai-pajak.vercel.app/register` 접속
2. 회사 대표자 또는 재무 담당자 이메일로 가입
3. 비밀번호 요건: **8자 이상 + 대문자 + 소문자 + 숫자 + 특수문자**
4. 가입 즉시 `CUSTOMER` 역할이 부여되고, 고객 유형은 **회사(COMPANY)** 로 설정됩니다.

### 2.2. 첫 로그인 후 해야 할 일 (순서대로)

| # | 위치 | 할 일 |
|---|---|---|
| 1 | 사이드바 → **회사프로필** | NPWP, NIB, KBLI, 사업장 주소, 대표자 정보 입력 |
| 2 | 사이드바 → **설정 → 보안** | 2단계 인증(TOTP) 활성화 권장 |
| 3 | 사이드바 → **거래상대방** | 주요 공급업체·매출처 NPWP 등록 (PPh23/PPN 자동 분개에 사용됨) |
| 4 | 사이드바 → **통합설정** | Accurate / Mekari Jurnal / Open Banking 연결 (선택) |
| 5 | 사이드바 → **청구 → 플랜 선택** | UMKM / Basic / Pro 중 회사 규모에 맞는 요금제 선택 |

**회사프로필이 완성되어야 월 신고가 가능합니다.** NPWP 15자리가 정확히 입력되지 않으면 DJP 제출 단계에서 거부됩니다.

## 3. 대시보드 둘러보기

로그인 직후 첫 화면이 **법인 대시보드**입니다. 상단에는 "이번 달 할 일" 카드가 자리잡고, 그 아래로 현재 요금제 위젯(`CurrentPlanWidget`), 미결 신고 목록, 최근 결제 상태가 표시됩니다.

### 3.1. 사이드바 메뉴 (법인 전용 구성)

다음은 법인 고객에게 보이는 메뉴입니다. 역할 기반으로 **월 신고·연말정산·결제·설정 3블록**으로 분리됩니다.

**월 신고**
- **대시보드** — 이번 달 현황 한눈에
- **뉴스** — 세법 변경·규정 업데이트 (PMK, SE 등)
- **월 신고 → PPh21** — 급여 원천징수
- **월 신고 → PPh23** — 서비스 원천세
- **월 신고 → UMKM (Final)** — 매출 0.5% 간편세 (해당 시)
- **월 신고 → PPN** — 부가세(VAT)
- **월 신고 → 세금청구** — eBilling/VA 번호 조회
- **제출현황** — `/submissions` 월별 신고 큐
- **신고건** — `/filings` 전체 신고 히스토리
- **인보이스 캡처** — 사진/PDF로 세금계산서 업로드
- **문서 업로드** — POA, 사업자등록증, 기타 증빙
- **세금달력** — DJP 법정 기한 확인
- **세금도구** — PPh21 시뮬레이터, PTKP 계산기 등

**연 신고**
- **연간정산 (SPT 1771)** — 법인소득세 연말신고
- **분개장** — 월간 장부
- **재무제표** — BS/IS 생성

**계정**
- **청구** — 현재 요금제, 결제 내역
- **회사프로필** — 법인 정보 수정
- **거래상대방 등록** — 공급처·매출처 NPWP 관리
- **통합설정** — 회계 소프트웨어·은행 연동
- **설정** — 프로필, 보안(2FA), 알림, 언어
- **도움말** — 본 매뉴얼 및 지원 문의

## 4. 매달 반복되는 핵심 업무 플로우

### 4.1. 플로우 A — 이번 달 PPh21(급여 원천세) 신고하기

**누가**: 경리 담당자 · 재무 담당자
**언제**: 매월 급여 지급 직후 (보통 월말)
**DJP 기한**: 다음 달 **10일까지 납부**, **20일까지 신고**

1. 사이드바 **월 신고 → PPh21** 진입
2. 상단 드롭다운에서 **신고 기간(Masa Pajak)** 선택 — 예: "2026년 3월"
3. **직원 명단 확인** — 이미 등록된 직원이 자동 로드됨. 신규 입사자는 이 화면에서 바로 추가 가능
4. **급여 입력** — 기본급, 수당(식비·교통비·직책), BPJS Kesehatan/Ketenagakerjaan, 보너스(THR 포함), Tax Allowance
5. **자동 계산** — PTKP(기본공제) 자동 반영, PPh21 금액 산출
6. **Payslip 확인** — 직원별 명세서 PDF 생성 가능 (출력/이메일 전송)
7. **검토** → **제출** 버튼 클릭
8. 상태가 `PENDING`으로 바뀌며 JTC 운영팀 큐로 전송됨
9. 운영팀이 **데이터 검토 → 수퍼바이저 승인 → eBilling 생성**까지 진행. 이 동안 사이드바 "제출현황"에서 단계를 실시간으로 볼 수 있음
10. **eBilling 번호 수신** (이메일/앱 알림) → 은행 또는 Open Banking으로 납부
11. 납부 영수증 업로드 → 운영팀이 **입금 확인 → DJP 제출 → BPE(전자접수증) 업로드** → 완료

### 4.2. 플로우 B — PPN(부가세) 신고하기

**언제**: 매월, 다음 달 말까지 (DJP 기한 ≈ 다음 달 30일)

1. **월 신고 → PPN** 진입
2. **Faktur Pajak 등록** 화면에서 두 가지 방법 중 택 1:
   - (a) **인보이스 캡처** 탭 → 세금계산서 사진/PDF 업로드 → OCR 자동 판독
   - (b) **거래상대방 + 수기 입력**
3. 매출(Faktur Keluaran)과 매입(Faktur Masukan) 구분
4. 시스템이 **PPN Keluaran − Masukan = 납부·환급액** 자동 계산
5. **제출** → 운영팀 큐 진입 → eBilling 생성 → 납부
6. PPN은 **e-Faktur 시스템**에도 업로드되어야 하므로, 운영팀이 Coretax/e-Faktur에 대리 등록합니다.

**요령**: 매입 Faktur에서 **공급업체 NPWP가 없거나 잘못되면 공제가 거부됩니다.** 인보이스 캡처 후 NPWP 필드를 꼭 확인하세요.

### 4.3. 플로우 C — 회계 프로그램(Accurate / Mekari Jurnal) 연동

1. 사이드바 **통합설정** 진입
2. 사용 중인 소프트웨어 카드에서 **연결** 클릭
3. OAuth 인증 창에서 회사 계정으로 로그인
4. 연결 완료 후 **데이터 동기화** 버튼 → 다음이 자동 동기됨:
   - 직원 마스터 (PPh21 계산용)
   - 급여 대장 (Payroll)
   - 매출·매입 인보이스 (PPN 계산용)
   - 재무제표 (연간 SPT 1771 준비용)

**Mekari Jurnal** 카드는 현재 "Sync Employees / Sync Invoices / Sync Financial" 3종을 지원합니다. **Accurate**는 Payroll까지 포함한 4종을 지원합니다.

## 5. 요금제 선택 가이드

법인은 **월 구독제**입니다. 구독은 매월 자동 갱신되며 결제는 Midtrans를 통해 진행됩니다.

| 플랜 | 월 요금 (VAT 별도) | 직원 수 | 원천세 건/월 | PPN 건/월 | 적합한 회사 |
|---|---|---|---|---|---|
| **UMKM** | Rp 500,000 | 최대 10명 | 최대 30건 | 0건 (UMKM 대상) | 매출 48억 루피아 이하 소기업, Final Tax 적용 |
| **Basic** | Rp 1,500,000 | 최대 50명 | 최대 100건 | 최대 200건 | 중소법인, 일반과세 사업자 |
| **Pro** | Rp 3,000,000 | 최대 1,000명 | 최대 200건 | 최대 500건 | 중견·대기업, 다수 공급업체 |

**VAT 11% 별도**. 결제 화면에서는 VAT 포함 금액이 함께 표시됩니다.

**플랜을 초과하면?** 운영팀이 자동으로 감지하여 JTC 마스터 담당자에게 알리고, **맞춤 견적(Custom Pricing Quote)**이 발급됩니다. 이 견적을 수락하면 다음 달부터 커스텀 요금으로 전환됩니다.

**플랜 변경하기**: 사이드바 **청구 → 플랜 변경** → 원하는 플랜 카드 → **업그레이드** 클릭 → Midtrans 결제 창에서 결제하면 즉시 전환됩니다.

### 5.1. 플랜 추천 엔진

`CurrentPlanWidget`(대시보드 우측)은 지난 3개월 동안 회사의 실제 사용량(직원·원천세·PPN 건수)을 분석하여 **권장 플랜**을 자동으로 제안합니다.

- 녹색 체크 — 현재 플랜이 적합함
- 노란색 경고 — 한도에 근접, 곧 업그레이드 권장
- 빨간색 — 이미 한도 초과, 즉시 업그레이드 또는 맞춤 견적 필요

## 6. 결제와 청구

### 6.1. 매월 청구서 확인
- 사이드바 **청구** → 최근 6개월 청구 내역, 상태(Paid/Pending), 결제일 확인
- 미결제 항목에서 **지금 결제** → Midtrans 결제 페이지로 이동

### 6.2. 지원 결제 수단
- 은행 이체 (BCA, Mandiri, BNI, BRI — Virtual Account)
- GoPay, OVO, DANA, ShopeePay
- 신용카드 (VISA/Master)

### 6.3. 세금 납부 구별
구독 요금(월 요금제)과 **실제 세금 납부**(eBilling)는 별도입니다. 세금은 다음 경로로 납부합니다.

1. 월 신고 제출 → 운영팀 승인 → **eBilling 번호 수신**
2. 사이드바 **월 신고 → 세금청구** 에서 eBilling 번호와 기한 확인
3. 인터넷뱅킹 → 국고 납부 → VA 번호 입력 → 납부
4. 영수증을 **제출현황 → 해당 건 → 증빙 업로드**
5. 운영팀이 입금 확인 후 DJP 제출 완료

## 7. 문서와 증빙 관리

### 7.1. 문서 업로드
- **문서 업로드** 메뉴 → 드래그앤드롭 또는 파일 선택
- 지원 포맷: PDF, JPG, PNG
- 서류 유형 선택 — POA, NPWP 증서, Akta Pendirian, SPT 영수증 등
- 업로드 후 OCR이 자동으로 핵심 정보를 추출합니다

### 7.2. 인보이스 캡처 (OCR)
- **인보이스 캡처** 메뉴 → 세금계산서(Faktur Pajak) 사진 업로드
- 자동 추출 정보: 공급업체 NPWP, 발행일, 총액, PPN, 품목
- 추출 결과를 **반드시 검토**하세요. 금액이나 NPWP 오탈자가 있으면 PPN 공제가 거부됩니다.

### 7.3. POA (Power of Attorney, 위임장)
법인 SPT 제출은 법인 대표 명의지만 실제 서명·송신은 JTC 세무사가 수행하므로, **POA 위임장**이 필요합니다.

1. **문서 → POA 등록**
2. 양식 다운로드 → 대표 서명·도장 → 스캔 업로드
3. JTC에서 유효성 검증 후 승인
4. 이후 모든 신고가 이 POA를 근거로 제출됩니다

유효 기간이 만료되면 자동 알림이 오며, 만료된 POA로는 제출이 불가능합니다.

## 8. 커뮤니케이션과 알림

### 8.1. 알림 채널
- **앱 내 알림** (사이드바 상단 종 아이콘) — 신고 상태 변경, 결제 요청, eBilling 수신
- **이메일** — 주요 상태 변경, 월간 요약 리포트
- **WhatsApp** — 긴급 납부 기한 리마인드 (설정에서 활성화)
- **텔레그램** — 선택 사항, 봇 연결 후 동일 알림 수신 가능

### 8.2. 담당 세무사와 소통
법인 고객에게는 **전담 JTC 세무사**가 배정됩니다. 사이드바 상단의 "내 담당자" 영역에서 이름과 연락처를 확인할 수 있고, 문의는 앱 내 메시지, 이메일, 혹은 담당자 WhatsApp으로 직접 보낼 수 있습니다.

## 9. 자주 묻는 질문

**Q. NPWP를 잘못 입력했습니다. 어떻게 수정하나요?**
A. **회사프로필** 에서 본인이 직접 수정 가능합니다. 단, 이미 제출된 과거 신고는 운영팀에 수정 요청을 해야 합니다(정정신고).

**Q. 신고 제출 버튼을 눌렀는데 "제출현황"에 안 보입니다.**
A. `제출현황` 페이지 상단 필터가 "PENDING"으로 되어 있는지 확인하세요. 만약 없다면 브라우저 캐시를 지우고 재로그인 후 다시 확인하세요.

**Q. eBilling 번호가 오지 않았습니다.**
A. 보통 운영팀 승인 후 15분~2시간 내에 생성됩니다. 24시간 초과 시 담당 세무사에게 연락하세요.

**Q. 플랜을 다운그레이드할 수 있나요?**
A. 네. 현재 사용량이 낮은 플랜의 한도 이내일 때만 가능합니다. **청구 → 플랜 변경** 에서 조건을 만족하면 다운그레이드 버튼이 활성화됩니다.

**Q. 연간 SPT 1771은 언제 작성하나요?**
A. 회계연도 종료 후 다음 해 4월 말까지 신고 기한입니다. 현재 버전에서는 SPT 1771 풀 자동 생성은 **준비 중(BETA)** 이며, 월 신고 + 재무제표 데이터를 기반으로 운영팀이 수동 작성해 드립니다.

**Q. 비밀번호를 잊었습니다.**
A. 로그인 화면의 **비밀번호 찾기** → 가입 이메일로 재설정 링크가 발송됩니다.

**Q. 외부 세무사무소(JTC 아님)가 우리 회사를 대행하게 하고 싶습니다.**
A. 가능합니다. 외부 세무사무소가 본인들의 AI Pajak 계정으로 본 회사를 고객으로 등록하면, 그 사무소 소속 컨설턴트가 신고를 대행할 수 있습니다. 자세한 흐름은 별도로 외부 사무소 매뉴얼(`02-external-consultant.md`)을 참고하십시오.

## 10. 문제가 생겼을 때

- **앱 내 도움말** → **문의 남기기**
- **긴급 기한 관련**: 담당 JTC 세무사에게 직접 WhatsApp/이메일
- **결제 문제**: 청구 화면 → "결제 문의" 버튼
- **기술 장애**: 로그인 직후 나타나는 에러 메시지 스크린샷을 JTC 지원팀에 전달

## 11. 주요 용어

| 용어 | 뜻 |
|---|---|
| **NPWP** | 인도네시아 납세자번호 (Nomor Pokok Wajib Pajak) |
| **SPT** | 세무신고서 (Surat Pemberitahuan). 월·연 단위 |
| **SPT Masa** | 월간 신고서 |
| **SPT Tahunan** | 연간 신고서 |
| **PPh** | 소득세 (Pajak Penghasilan). PPh21=급여, PPh23=서비스, PPh25=분납, PPh4(2)=최종세 |
| **PPN** | 부가세 (Pajak Pertambahan Nilai) = VAT, 기본 11% |
| **Faktur Pajak** | 세금계산서 |
| **PTKP** | 기본 공제액 (Penghasilan Tidak Kena Pajak) |
| **DJP** | 국세청 (Direktorat Jenderal Pajak) |
| **Coretax** | 2025년부터 DJP가 운영하는 통합 세무 시스템 |
| **eBilling** | 전자납부 번호 체계 |
| **BPE** | 전자접수증 (Bukti Penerimaan Elektronik) |
| **UMKM** | 소상공인 (Usaha Mikro Kecil Menengah) |
| **POA** | 위임장 (Power of Attorney) |
| **BPJS** | 인도네시아 4대보험 (Kesehatan + Ketenagakerjaan) |
