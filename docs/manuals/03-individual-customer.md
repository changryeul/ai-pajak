# 개인 납세자 매뉴얼

> **대상**: 인도네시아에서 **개인 NPWP**로 세금을 내고 매년 **SPT Pribadi(개인 연말정산)**를 해야 하는 개인 납세자
>
> **한 줄 요약**: 법인과 달리 개인은 **매년 1회** 연간 신고만 하면 됩니다. 월 구독이 아니라 **건당(1770SS/1770S/1770)** 요금을 냅니다.

## 1. AI Pajak이 개인에게 제공하는 것

- **세 가지 SPT 양식**을 자동 생성·검토: **1770SS**(단순 직장인), **1770S**(복수 소득자), **1770**(사업소득자·프리랜서)
- **A1/1721-A1 원천징수영수증 OCR 업로드** → 회사가 이미 낸 세금과 소득이 자동 채워짐
- **PTKP(기본공제) 자동 계산** — 결혼 여부, 부양가족 수에 따라 자동 반영
- **환급 여부 자동 판정** — 이미 낸 세금이 계산된 세액보다 많으면 환급 신청 가능
- **JTC 세무사 검수** — 제출 전 전문가 최종 검토
- **건당 결제** — 필요한 해에만 사용

## 2. 가입과 첫 설정

### 2.1. 회원가입
1. `https://ai-pajak.vercel.app/register`
2. 본인 이메일로 가입
3. 가입 직후 고객 유형을 **개인(INDIVIDUAL)**으로 선택 (기본값)

### 2.2. 첫 로그인 후 필수 입력

| # | 위치 | 할 일 |
|---|---|---|
| 1 | **내 프로필** | 이름, NPWP(16자리), 생년월일, 주소, 연락처 입력 |
| 2 | **내 프로필 → 가족/PTKP 정보** | 결혼 여부, 부양가족 수 (0~3명). 이 값으로 PTKP가 자동 결정됨 |
| 3 | **설정 → 보안** | 2단계 인증(TOTP) 활성화 (선택 권장) |

NPWP가 정확해야 DJP 제출이 가능하므로, 입력 후 **유효성 검사 체크**를 꼭 확인하세요.

## 3. 대시보드와 사이드바 (개인 전용)

법인과 달리 개인 대시보드는 **연간 1회 신고**에 최적화되어 있습니다. 월 신고 메뉴가 **아예 나타나지 않습니다**.

**핵심 메뉴**
- **대시보드** — 올해 SPT 진행 상태 (Not Started / In Progress / Submitted / Refund Pending 등)
- **뉴스** — 세법 업데이트
- **연 신고 → SPT Pribadi** — 1770SS/1770S/1770 작성 화면 (핵심 메뉴)
- **신고건** — 과거 신고 이력
- **인보이스 캡처** — 증빙 OCR
- **문서** — PDF·이미지 보관함
- **세금달력** — 연말정산 기한
- **세금도구** — PPh21 시뮬레이터, 환급 예상 계산기

**계정**
- **청구** — 건당 결제 내역
- **내 프로필** — 개인 정보 (법인처럼 "회사 프로필"이 아님)
- **거래상대방** — 프리랜서 고객이 있는 경우 사용
- **설정 / 도움말**

## 4. 매년 해야 할 유일한 플로우 — SPT Pribadi 작성·제출

### 4.1. 먼저 어떤 양식이 내게 맞는지 결정하기

| 양식 | 선택 기준 | 가격 |
|---|---|---|
| **1770SS** | 단순 직장인: **연 소득 6천만 루피아 이하**, 단일 고용주, 고정급여만 | **Rp 100,000** / 건 |
| **1770S** | 중·고소득 직장인, 또는 근로소득 + 이자·배당·임대 같은 기타소득이 있는 경우 | **Rp 200,000** / 건 |
| **1770** | 사업자·프리랜서·복수 사업장, 장부 기장 필요, 해외 소득 포함 | **Rp 300,000** / 건 |

VAT 11% 별도.

작성 화면 상단에 **"어떤 양식이 맞나요?" 도우미**가 있어, 질문 2~3개에 답하면 자동으로 해당 양식으로 이동합니다.

### 4.2. 플로우 — 1770S 작성 예시

1. 사이드바 **연 신고 → SPT Pribadi** 진입
2. 화면에서 **"1770S 시작"** 버튼 클릭
3. **Step 1 — 기본 정보**: 신고 연도(예: 2025년 귀속 → 2026년 신고), NPWP 확인
4. **Step 2 — 근로소득 입력**
   - 방법 A: **A1/1721-A1 OCR 업로드** — 회사에서 받은 원천징수영수증을 사진 또는 PDF로 올리면 OCR이 모든 항목을 자동 채움
   - 방법 B: 수기 입력 — 급여 총액, 보너스, THR, 이미 원천징수된 PPh21 세액
5. **Step 3 — 기타 소득**: 이자, 배당, 임대 수입 등
6. **Step 4 — 공제**: PTKP(자동), Zakat, 연금(BPJS Ketenagakerjaan 개인 부담)
7. **Step 5 — 자산/부채**: 주요 자산 목록 (예금, 부동산, 차량)과 부채 잔액
8. **Step 6 — 계산 요약**: 시스템이 자동으로 계산:
   - 과세표준
   - 누진세율 적용 후 세액
   - 이미 원천징수된 금액
   - **납부해야 할 금액** 또는 **환급 금액**
9. **Step 7 — 검토**: 빨간 경고가 있으면 수정. 녹색이면 **제출**
10. 결제 화면 → Midtrans로 Rp220,000 (VAT 포함) 결제
11. 결제 완료 → JTC 세무사가 **24~48시간 이내** 검토
12. 검토 완료 후 DJP에 제출, **BPE(전자접수증) PDF**가 이메일과 사이드바 "신고건"으로 발송됨

### 4.3. 환급 신청
계산 결과가 환급이면 6단계 화면에 **"환급 신청"** 체크박스가 나타납니다.

1. 체크 → 환급 받을 은행 계좌 입력
2. 제출 → DJP가 감사(Verifikasi) 진행 (보통 6~12개월 소요)
3. 감사 완료 시 국세청이 해당 계좌로 직접 송금

## 5. 문서·증빙 업로드

### 5.1. A1/1721-A1 업로드
회사에서 매년 2~3월에 발급해 주는 **1721-A1 원천징수영수증**이 가장 중요한 증빙입니다.

- **문서 → 업로드** → 유형을 "1721-A1"로 선택 → 파일 올리기
- OCR이 자동으로 인식하는 항목: 회사명, NPWP, 연도, 총급여, PPh21 원천징수액, BPJS
- 결과를 반드시 확인하세요. 금액 1자리만 틀려도 신고 결과가 크게 달라집니다.

### 5.2. 임대·이자·배당 증빙
- 은행이 발급한 **bukti potong PPh 4(2)** 영수증
- **문서 → 업로드** → 유형 "bukti potong" → 자동 분류

### 5.3. 프리랜서 인보이스 (1770 해당자)
본인이 발행한 인보이스 사본, 고객이 차감한 PPh23/PPh21 원천세 증빙을 **인보이스 캡처** 에서 OCR로 업로드. 시스템이 자동으로 사업소득·필요경비 항목에 반영합니다.

## 6. 결제

개인은 **월 구독이 아닙니다**. 신고 제출 시점에 **1회성 결제**만 발생합니다.

1. SPT 작성 완료 후 "제출" → Midtrans 결제 창
2. 지원 결제 수단:
   - 은행 이체 (BCA/Mandiri/BNI/BRI VA)
   - 전자지갑 (GoPay, OVO, DANA, ShopeePay)
   - 신용카드
3. 결제 완료 시 즉시 JTC 세무사 큐로 전달
4. 청구 내역은 **청구** 메뉴에서 언제든 조회 가능

**수수료 기준**: 제출 완료 기준이 아니라 **"제출" 버튼을 누르는 순간** 결제가 발생합니다. 결제 후 취소가 어렵기 때문에, 제출 전에 **Step 7 검토** 에서 수치를 반드시 확인하세요.

## 7. 세금달력과 기한

### 7.1. 개인 SPT 기한
- **연간 귀속**: 1월 1일 ~ 12월 31일
- **신고 기한**: 다음 해 **3월 31일**까지
- **지연 신고 과태료**: Rp 100,000 (1770SS/1770S), Rp 1,000,000 (1770)

### 7.2. AI Pajak 알림
사이드바 상단 종 아이콘과 이메일로 다음 시점에 알림이 자동 발송됩니다.
- 1월 초 — "올해 SPT 준비 시작하세요"
- 2월 말 — "A1 받으셨나요? 이제 업로드 가능"
- 3월 15일 — "2주 남았습니다"
- 3월 28일 — "3일 남았습니다, 지금 제출하세요"

## 8. 자주 묻는 질문

**Q. 작년에 AI Pajak을 쓰지 않았는데 올해부터 써도 되나요?**
A. 네. 과거 신고 데이터가 없어도 새로 시작할 수 있습니다. 과거 자료를 올리면 사이트가 비교 분석까지 해 줍니다.

**Q. 원천징수영수증(1721-A1)을 못 받았습니다.**
A. 회사 인사팀에 발급 요청하세요. 법적으로 회사는 이를 발급할 의무가 있습니다. 끝내 못 받으면 수기 입력 + 급여명세서로 대체 가능합니다.

**Q. 해외 소득이 있습니다. 어떤 양식을 써야 하나요?**
A. **1770(풀)**을 선택하세요. 해외 근로소득·투자 수익 섹션이 활성화됩니다. 이중과세방지협정(P3B) 적용도 가능합니다.

**Q. 결제했는데 몇 시간이 지나도 검토가 시작되지 않습니다.**
A. 제출 → 검토 시작 사이 최대 24시간 여유가 있습니다. 그 이상 지연 시 앱 내 도움말로 문의하세요.

**Q. 한 번 제출한 SPT를 수정할 수 있나요?**
A. DJP 제출 **전**이면 JTC 세무사에게 요청해 수정 가능. 제출 후 오류를 발견했다면 **정정신고(SPT Pembetulan)**가 필요하며 이는 별도 서비스입니다.

**Q. 프리랜서입니다. 여러 고객에게서 소득이 있는데 1770S로 충분한가요?**
A. 연간 매출이 **Rp 4.8억 이하**이고 UMKM Final(0.5%)을 선택했다면 1770S로 가능합니다. 사업 규모가 크거나 일반과세를 선택한다면 **1770**이 필요합니다. 판단이 어려우면 시작 화면의 도우미를 이용하세요.

**Q. 2FA를 설정했는데 기기를 잃어버렸어요.**
A. **설정 → 보안 → 복구 코드**에서 미리 받은 코드로 복구하거나, 지원팀에 본인 확인 후 재설정 요청.
