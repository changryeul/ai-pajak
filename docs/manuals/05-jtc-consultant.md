# JTC 세무사 매뉴얼

> **대상**: Jakarta Tax Consulting(JTC) 내부 소속 **세무사·컨설턴트**
>
> **두 가지 역할**:
> - **CONSULTANT** — 일반 세무사. 배정된 고객의 월·연 신고 작성
> - **TAX_ADVISOR** — 선임 세무사 (자격증 소지자). 실제 DJP 제출 권한 보유 (Hard Rule 3), 팀 관리 권한
>
> 📌 **네이밍**: `CONSULTANT` / `TAX_ADVISOR` 두 role 은 **세무 컨설팅 법인 (EXTERNAL tax_partner) 직원도 함께 사용**합니다. 소속은 `consultant.tax_partner_id` 로만 결정. 본 매뉴얼은 **JTC 내부 직원 관점** — 세무 컨설팅 법인 직원의 매뉴얼은 [`02-external-consultant.md`](./02-external-consultant.md). (`_JTC` 접미사는 P3 로 2026-07-05 제거 완료.)

## 1. JTC 세무사의 책임 범위

JTC는 AI Pajak 플랫폼 **운영사**이자 **가장 큰 세무 법인 고객**입니다. JTC 세무사는 다음을 담당합니다.

- 법인·개인 고객에게 **1:1 전담 배정**되어 월·연 세무 신고 작성·검토·컨설팅
- 고객이 입력한 데이터의 정확성 검증
- 특수 상황(이전가격, 다중 엔티티, 이상 거래) 조사·대응
- 고객과의 직접 소통 (WhatsApp, 이메일, 현장 미팅)
- `CONSULTANT` 는 **제출 준비**까지, **실제 DJP 제출**은 `TAX_ADVISOR` 또는 운영팀이 수행 (Hard Rule 3 — Tax Filing Actor ≠ Platform)

## 2. 계정과 역할 부여

### 2.1. 계정 생성
JTC 세무사 계정은 **TAX_ADVISOR 또는 PLATFORM_ADMIN**이 생성합니다. 일반 회원가입으로는 JTC 역할을 얻을 수 없습니다.

- 초대 이메일 수신 → 링크 클릭 → 비밀번호 설정 → 로그인
- 시스템이 자동으로 `consultant` 테이블에 레코드를 만들고 `tax_partner_id`를 **JTC 내부 파트너**로 연결
- **2FA 필수** — 고객 데이터 접근 계정이므로 첫 로그인 시 TOTP 등록 요구

### 2.2. CONSULTANT vs TAX_ADVISOR

| 기능 | CONSULTANT | TAX_ADVISOR |
|---|:-:|:-:|
| 고객 배정·조회 | ✓ | ✓ |
| 월·연 신고 작성 | ✓ | ✓ |
| 신고 큐 제출 | ✓ | ✓ |
| **DJP 최종 제출 권한** | — | ✓ |
| **팀 관리 (/admin/team)** | — | ✓ |
| 고객 추가·삭제 | ✓ | ✓ |
| 이상 탐지·TP·다중 엔티티 도구 | ✓ | ✓ |

## 3. 대시보드와 사이드바

### 3.1. 첫 화면
로그인하면 **내가 담당한 고객 요약**, **오늘 처리할 신고 건**, **이번 주 마감 임박 건**, **최근 이상 탐지 결과**가 표시됩니다.

### 3.2. 사이드바 메뉴 (JTC 세무사)

**세무 작업**
- **대시보드**
- **뉴스** — 세법·PMK 업데이트
- **고객** (`/customers`) — 본인 담당 고객 목록 (여러 고객 동시에 처리 가능)
- **월 대시보드** (`/tax/monthly-dashboard`) — 담당 고객 × 신고 유형 교차표
- **월 신고 → PPh21 / PPh23 / UMKM / PPN / 세금청구**
- **연 신고 → 연간정산 / 분개장 / 재무제표 / SPT Pribadi**
- **제출 현황** — 운영팀 큐 상태
- **신고건** — 담당 고객의 전체 신고 이력
- **인보이스 캡처**, **문서 업로드**, **세금달력**, **세금도구**

**세무 관리 (JTC 전용)**
- **일괄 PPh21** (`/tax/pph21-bulk`) — 여러 고객 급여 한 번에 처리
- **이상 탐지** (`/tax/anomaly`) — 고객 데이터 중 통계적으로 이상한 항목 자동 발견
- **이전가격(TP)** (`/tax/transfer-pricing`) — 해외 관계사 거래 분석
- **다중 엔티티** (`/tax/multi-entity`) — 그룹사 통합 조회
- **클라이언트 보고** (`/tax/report`) — 고객별 정기 리포트 생성

**관리** (TAX_ADVISOR 전용)
- **팀 관리** (`/admin/team`) — JTC 세무사·컨설턴트 초대·비활성화

**계정**
- **회사 프로필**, **거래상대방**, **통합설정**, **설정**, **도움말**

**보이지 않는 메뉴**: 운영팀 큐(`/operator/*`), 마스터 대시보드(`/admin/master`), 플랫폼 모니터링(`/admin/monitoring`)은 JTC 세무사 사이드바에 노출되지 않습니다.

## 4. 핵심 플로우

### 4.1. 플로우 A — 신규 고객 배정받기

**시나리오**: JTC 영업팀이 신규 법인 계약을 성사시키면 고객이 시스템에 등록되고 담당 세무사에게 배정됩니다.

1. **고객** 메뉴에서 새 고객이 내 목록에 나타남
2. **고객 상세 → 프로필 탭** → NPWP, 회사 유형, 매출 규모, 직원 수 확인
3. **POA 탭** → 위임장 업로드 (고객사 대표 서명본)
4. **메모 탭** → 첫 만남 요약, 특이사항 기록 (예: "외국인 주주 보유", "PPN 면제 품목 포함")
5. **통합설정 탭** → 고객사 Accurate/Mekari Jurnal 연동 (고객이 OAuth 승인 필요)
6. **고객에게 온보딩 이메일 자동 발송** 확인 (시스템이 자동 처리)

### 4.2. 플로우 B — 월별 신고 작성 (담당 고객 1개)

**목표**: 이번 달 해당 고객의 PPh21/PPh23/PPN 전부 제출하기

1. **월 대시보드** → 담당 고객 목록에서 해당 고객 선택 → 이번 달 컬럼 확인
2. 비어있는 셀 클릭 → 해당 신고 유형 입력 화면 이동
3. **PPh21**: 고객사 급여 대장 업로드 또는 Accurate 연동에서 자동 가져오기 → 검토 → 제출 준비
4. **PPh23**: 거래 내역에서 원천세 대상 건만 자동 필터링 → NPWP 누락 확인 → 제출 준비
5. **PPN**: Faktur Pajak 업로드 또는 Mekari Jurnal 동기 → 매출·매입 분류 → 계산 → 제출 준비
6. 모든 항목에서 **"제출 준비"**가 완료되면 **CONSULTANT**는 "검토 요청" 으로 TAX_ADVISOR에게, TAX_ADVISOR는 바로 **"운영팀 큐로 제출"** 가능
7. 큐 상태는 **제출 현황** 에서 실시간 추적 (DATA_REVIEW → APPROVED → ... → COMPLETED)

### 4.3. 플로우 C — 일괄 PPh21 (여러 고객 한 번에)

**시나리오**: 월말에 담당 고객 10개사의 PPh21을 한 번에 처리해야 함

1. **세무 관리 → 일괄 PPh21** (`/tax/pph21-bulk`)
2. 처리할 고객 체크박스로 다중 선택
3. 공통 신고 기간 선택 (예: "2026년 3월")
4. 고객별 급여 데이터 소스 선택:
   - (a) 엑셀 템플릿 다운로드 → 고객별 시트에 급여 입력 → 업로드
   - (b) Accurate 연동 고객은 자동 가져오기
5. 시스템이 고객별 PPh21 개별 계산 → 오류 요약표 표시
6. 오류 0건 확인 → **전체 제출**
7. 큐에 10건 동시 진입, 운영팀이 처리

### 4.4. 플로우 D — 이상 탐지 활용

1. 사이드바 **세무 관리 → 이상 탐지**
2. 기간 선택 (이번 달 or 지난 3개월)
3. 시스템이 다음을 자동 플래그:
   - 같은 공급업체인데 금액이 평소 대비 ±30% 초과
   - NPWP가 DJP 등록부와 불일치
   - PPN 매입인데 Faktur가 e-Faktur에 등록되지 않음
   - 급여가 PTKP 하한에 붙어 있음 (탈세 의심)
4. 항목 클릭 → 근거 데이터 확인 → 고객에게 문의 또는 반려
5. 처리 완료한 항목은 **"확인 완료"** 표시 → 통계에 반영

### 4.5. 플로우 E — 이전가격(TP) 분석

**TP**는 해외 관계사 간 거래의 정상가격 검증입니다. 그룹사 고객이 있다면 연 1회 TP 보고서를 준비해야 합니다.

1. **세무 관리 → 이전가격**
2. 분석 대상 고객 선택
3. 해외 관계사 거래 내역 입력·업로드
4. 시스템이 **Arm's Length Range** 계산 (OECD 가이드라인 기반)
5. 결과 PDF 생성 → 고객 보고서로 첨부

## 5. 팀 관리 (TAX_ADVISOR 전용)

`/admin/team` 에서 JTC 내부 세무사·컨설턴트를 관리합니다.

### 5.1. 팀원 초대
1. **팀 관리 → 팀원 초대**
2. 이메일 입력, 역할 선택 (CONSULTANT 또는 TAX_ADVISOR)
3. 초대 메일 발송 → 초대 링크 클릭 → 비밀번호 설정
4. 자동으로 JTC 내부 `tax_partner_id` 에 연결되며 `consultant` 레코드 생성

### 5.2. 고객 재배정
- 팀원이 퇴사하거나 휴직하면 담당 고객을 다른 세무사에게 일괄 재배정 가능
- **팀 관리 → 해당 팀원 → 담당 고객 이관** → 받을 세무사 선택 → 확인
- `customer_consultant` 테이블에서 이전 연결을 비활성화하고 새 연결을 활성화

### 5.3. 팀원 비활성화
- 퇴사자 계정은 삭제 대신 **비활성화**
- 감사 로그와 과거 신고 이력은 보존됨
- 비활성화 즉시 로그인 차단, 세션 만료

## 6. 보고와 커뮤니케이션

### 6.1. 클라이언트 리포트 생성
`/tax/report` 에서 고객별 정기 리포트를 만듭니다.

- **월간 세무 요약**: 이번 달 납부 세금, 주요 변동, 다음 달 예상 부담
- **연간 요약**: 연초 vs 연말 세무 지표 비교, 최적화 기회
- **특별 이벤트**: 세법 개정 영향 보고

PDF로 생성 후 이메일 자동 발송 또는 앱 내 고객 메시지로 전달.

### 6.2. 고객 직접 연락
- **고객 상세 → 메시지 탭** → 앱 내 메시지 발송 (고객 앱에 알림)
- **WhatsApp 바로가기** → 고객 WhatsApp 번호로 외부 앱 열림
- **이메일** — 고객 프로필에서 직접 메일 작성

## 7. 일반 규칙과 주의사항

### 7.1. Hard Rule 준수
1. **PLATFORM_ADMIN은 고객 데이터에 접근 불가** — JTC 세무사가 유일한 고객 데이터 접근 계정
2. **Consultant는 JTC 소속** — 이 규칙은 FK로 강제됨
3. **Tax Filing Actor ≠ Platform** — 실제 DJP 제출은 TAX_ADVISOR 또는 운영팀
4. **Billing Collector ≠ Service Provider** — 결제 처리는 SYSTEM 역할이 담당
5. **모든 쓰기 조치에 감사 로그** — `withAudit` 미들웨어 자동 기록

### 7.2. 고객 데이터 취급
- 고객의 개인·재무 데이터는 업무 외 열람 금지
- 외부(가족, 타 법인)에 내용 공유 금지
- 스크린샷·PDF 다운로드는 업무 파일에만 저장, 개인 기기 저장 금지

### 7.3. 감사 로그
- 모든 SELECT/INSERT/UPDATE/DELETE는 감사 로그에 기록됩니다
- `actor_user_id`, `activity_type`, `activity_details`, IP, 타임스탬프 저장
- 분기별 감사 점검에서 Master가 전체 로그 검토

## 8. 자주 묻는 질문

**Q. CONSULTANT인데 신고 제출 버튼이 회색입니다.**
A. 최종 제출 권한은 TAX_ADVISOR에게만 있습니다. **"검토 요청"** 으로 상신하면 선임 세무사가 최종 제출합니다.

**Q. 담당 고객이 아닌데 고객 목록에 나타납니다.**
A. `customer_consultant` 배정 기록이 남아 있어서입니다. 팀 관리에서 이관하거나 배정을 해제해달라고 요청하세요.

**Q. Accurate 연동이 끊어졌습니다.**
A. OAuth 토큰 만료입니다. 고객에게 통합설정 → Accurate → 재연결 요청 메시지를 보내세요. 고객이 직접 재인증해야 합니다.

**Q. 이전가격 보고서 샘플이 있나요?**
A. `/tax/transfer-pricing` 하단에 JTC 표준 TP 보고서 템플릿 링크가 있습니다. 2024 OECD 가이드라인 기준.

**Q. 이상 탐지에서 false positive가 너무 많습니다.**
A. **설정 → 이상 탐지 민감도** 에서 임계값 조정 가능. 과거 확인된 케이스는 자동으로 화이트리스트에 추가됩니다.

**Q. 팀 관리에서 다른 TAX_ADVISOR를 비활성화할 수 있나요?**
A. 동료 TAX_ADVISOR를 비활성화하려면 최소 2명의 다른 ADVISOR 동의가 필요합니다 (권한 남용 방지). 단독 실행 시 거부됩니다.
