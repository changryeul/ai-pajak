> **준비물**: 노트북 + 인터넷 + 데모 계정 로그인 (아래 계정 참조)
>

## 데모 흐름 (10분)

### Opening (1분) — 공감 + 문제 제기

> "선생님, 지금 고객이 몇 분이세요? 30명? 35명?
> 그 이상 늘리고 싶어도 **월 신고 마감 때문에** 물리적으로 어렵지 않으시죠?
> 저희 AI Pajak이 **그 한계를 깨드리겠습니다.**"

---

### Scene 1 (2분) — 대시보드 첫인상

**로그인**: `demo.consultant@mitrapajak.com`으로 로그인

보여줄 것:
1. **대시보드** → "내 고객 3명, 이번 달 미결 신고 5건" 요약 카드
2. **ConsultantTierWidget** → 현재 Growth 플랜, 관리 고객 3/50명, 한도 여유
3. **사이드바** → 고객 관리, 월 대시보드, 일괄 PPh21, 이상 탐지 등

> "보시다시피, **고객별 신고 현황이 한눈에** 보입니다.
> 지금 PT Maju Jaya의 PPh21이 미완성이고, CV Berkah의 PPN이 오늘 마감입니다."

---

### Scene 2 (3분) — OCR 마법 ⭐ (핵심 데모)

**경로**: 사이드바 → 인보이스 캡처

보여줄 것:
1. 미리 준비한 **Faktur Pajak 사진**(또는 스마트폰 사진)을 업로드
2. **30초 안에** OCR이 자동 추출:
   - 공급업체 이름 + NPWP
   - 금액, PPN, 날짜
   - 매출/매입 자동 분류
3. 추출 결과 화면을 보여주며:

> "**사진 한 장이면 됩니다.** 고객이 WhatsApp으로 Faktur 사진만 보내주면,
> 저희 AI가 모든 항목을 자동으로 읽어냅니다.
> 수기로 입력하면 인보이스 1장에 10분, 100장이면 16시간.
> OCR이면 **100장 30분**입니다."

**임팩트 숫자**: 칠판/노트에 적어주기
```
수기: 100장 × 10분 = 16시간
OCR: 100장 × 30초 = 50분 (30배 빠름)
```

---

### Scene 3 (2분) — 일괄 PPh21 처리

**경로**: 사이드바 → 세무 관리 → 일괄 PPh21

보여줄 것:
1. 고객 3곳 체크박스 선택
2. 신고 기간 선택 (이번 달)
3. "이 3곳의 PPh21을 **한 번에** 처리합니다"
4. 계산 결과 표 — 고객별 직원 수, PPh21 총액, 오류 여부

> "고객마다 하나하나 열고 닫지 않아도 됩니다.
> **체크박스 3개, 버튼 1번**이면 3곳의 급여 원천세가 한꺼번에 처리됩니다.
> Growth 플랜에서 50곳까지 가능합니다."

---

### Scene 4 (2분) — 월 통합 대시보드

**경로**: 사이드바 → 세무 관리 → 월 대시보드

보여줄 것:
1. **고객 × 신고 유형 교차표** — 행: 고객, 열: PPh21/PPh23/PPN/Final
2. 각 셀의 상태: 완료(녹색) / 진행중(노랑) / 미시작(회색) / 기한 초과(빨강)
3. 미완성 셀을 클릭하면 바로 해당 신고 화면으로 이동

> "**한 화면에서 모든 고객의 월 신고 상태**를 봅니다.
> 빨간 셀이 있으면 즉시 클릭해서 처리.
> 이게 있으면 마감일에 허둥대지 않습니다."

---

### Scene 5 (1분) — 데이터 격리 (신뢰)

> "한 가지 중요한 것 — 선생님의 고객 데이터는 **완벽하게 격리**됩니다.
> JTC가 운영하는 플랫폼이지만, JTC 직원도 선생님의 고객을 볼 수 없습니다.
> 다른 세무사무소도 당연히 못 봅니다.
> **DB 레벨에서 격리**되어 있어서, 코드 실수로도 데이터가 새지 않습니다."

(기술적으로 물어보면: "Row Level Security라는 PostgreSQL 기능을 사용합니다")

## 데모에서 절대 하지 말 것

1. **결제 버튼 누르지 말 것** — PG 미연결 상태라 에러남. "결제는 별도 안내" 라고 넘기기
2. **DJP 제출 누르지 말 것** — DJP 연동 미완. "운영팀이 최종 제출합니다" 라고 설명
3. **admin 계정으로 전환하지 말 것** — 세무사에게 불필요한 복잡성
4. **빈 페이지가 나오는 메뉴 클릭하지 말 것** — 사전에 어떤 메뉴가 안전한지 확인

## 예상 질문 + 답변

**Q. Coretax에 직접 제출되나요?**
A. "현재는 JTC 운영팀이 Coretax에 대행 제출합니다. 선생님은 데이터만 입력하시면 됩니다. 향후 API 자동 제출도 준비 중입니다."

**Q. 우리 기존 고객 데이터를 이관할 수 있나요?**
A. "네. 엑셀 일괄 업로드 또는 Accurate/Mekari Jurnal 연동으로 기존 데이터를 가져올 수 있습니다."

**Q. 보안은 어떻게 되나요?**
A. "Row Level Security로 DB 레벨 격리, 2단계 인증(2FA) 지원, 모든 조치 감사 로그 기록. ISO 수준의 보안 구조입니다."

**Q. 고객이 직접 로그인할 수도 있나요?**
A. "네. 선택적으로 고객에게 별도 계정을 발급해서 본인 데이터를 조회하게 할 수 있습니다. 또는 선생님만 관리하셔도 됩니다."

**Q. JTC가 우리 고객 정보를 볼 수 있나요?**
A. "못 봅니다. 기술적으로 불가능하게 설계되어 있습니다. 신고 제출 시 운영팀이 메타데이터(이름, NPWP, 금액)만 처리합니다."

**Q. 3개월 후에 해지하면 데이터는?**
A. "데이터는 60일간 보존됩니다. 그 안에 엑셀 내보내기로 백업할 수 있습니다."
