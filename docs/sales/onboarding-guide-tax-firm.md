# 세무사무소 온보딩 가이드

> **대상**: AI Pajak에 새로 가입하는 외부 세무사무소
> **목표**: 가입 → 구독 → 첫 고객 등록 → 첫 월 신고 완료까지

---

## Step 1. 회원가입 (5분)

1. https://ai-pajak.vercel.app/register 접속
2. **"세무 컨설턴트 (외부 사무소)"** 선택
3. 사무소 정보 입력:
   - 대표자 이름
   - 이메일 (사무소 대표 메일)
   - 비밀번호 (8자 이상, 대/소/숫자/특수문자)
   - 사무소명
   - 사업자등록번호 (선택)
4. **가입** 클릭 → 즉시 로그인 가능

## Step 2. 구독 선택 (3분)

가입 직후 사이드바 → **청구** → **컨설턴트 플랜** 에서 구독을 선택합니다.

| 플랜 | 월 요금 (VAT 별도) | 고객 수 | 추천 |
|---|---|---|---|
| **Starter** | Rp 1,000,000 | 최대 10명 | 1인 사무소 |
| **Growth** | Rp 3,000,000 | 최대 50명 | **추천** — 일괄 처리 + 팀 초대 |
| **Enterprise** | Rp 8,000,000 | 무제한 | 대형 사무소 |

> **프로모션**: 현재 Growth 플랜 **3개월 무료 체험** 진행 중.
> JTC 담당자에게 문의하면 무료 체험 코드를 받을 수 있습니다.

## Step 3. 첫 고객 등록 (5분/고객)

사이드바 → **고객** → **신규 고객 추가**

### 법인 고객

| 필드 | 입력 | 필수 |
|---|---|---|
| 고객 유형 | **법인(COMPANY)** | ✅ |
| 회사명 | 예: PT Maju Jaya | ✅ |
| NPWP | 15~16자리 | ✅ |
| 주소 | 사업장 주소 | |
| 이메일 | 재무 담당자 이메일 | |
| 사업 분류 | TRADING / SERVICE / MANUFACTURING 등 | |
| 직원 수 | PPh21 계산에 사용 | |
| PKP 여부 | PPN 대상 여부 | |

### 개인 고객

| 필드 | 입력 | 필수 |
|---|---|---|
| 고객 유형 | **개인(INDIVIDUAL)** | ✅ |
| 이름 | 예: Budi Santoso | ✅ |
| NPWP | 16자리 | ✅ |
| 이메일 | | |

고객 등록 후 해당 고객이 **내 고객 목록**에 자동으로 나타납니다.

## Step 4. POA 위임장 등록 (고객당 2분)

세무 대행을 위해 **각 고객마다 POA(위임장)**가 필요합니다.

1. 고객 상세 페이지 → **POA 탭** → **업로드**
2. 고객 대표가 서명한 위임장 스캔본을 업로드
3. 유효기간 입력 (보통 1~2년)
4. POA가 승인되면 해당 고객의 신고 제출이 가능해집니다

> **Tip**: POA 만료 30일 전에 자동 알림이 옵니다.

## Step 5. 회계 소프트웨어 연동 (선택, 10분)

Accurate Online 또는 Mekari Jurnal을 사용 중이라면 연동하면 데이터 입력이 크게 줄어듭니다.

1. 사이드바 → **통합설정** → Accurate 또는 Mekari Jurnal 카드 → **연결**
2. 해당 소프트웨어에 로그인 → 권한 승인
3. DB 선택 (Accurate의 경우)
4. **동기화** → 매출/매입 인보이스 자동 가져오기

연동하면:
- **인보이스 수기 입력이 불필요**해집니다
- PPN 매출/매입 자동 분류
- 직원 정보 연동 (PPh21 계산용)

## Step 6. 첫 월 신고 작성 (고객당 15~30분)

### PPh21 (급여 원천세)

1. 사이드바 → **월 신고 → PPh21** → 고객 선택
2. 신고 기간 선택 (예: 2026년 3월)
3. **직원 명단** 확인 → 신규 입사자 추가
4. **급여 입력** — 기본급, 수당, BPJS, Tax Allowance
5. **자동 계산** → PTKP 반영, PPh21 산출
6. **제출** → JTC 운영팀 큐로 전송

### PPN (부가세)

1. 사이드바 → **월 신고 → PPN**
2. **인보이스 캡처** → Faktur Pajak 사진 업로드 (OCR 자동 입력)
3. 매출/매입 분류 확인
4. **자동 계산** → PPN Keluaran - Masukan = 납부/환급액
5. **제출**

### 일괄 PPh21 (Growth 이상)

여러 고객의 PPh21을 한 번에 처리:
1. 사이드바 → **세무 관리 → 일괄 PPh21**
2. 처리할 고객 체크박스 선택
3. 엑셀 템플릿 다운로드 → 데이터 입력 → 업로드
4. 오류 0건 → **전체 제출**

## Step 7. 제출 후 운영팀 처리 대기

제출 후에는 JTC 운영팀이 다음을 순차 처리합니다:
1. 데이터 검토
2. 수퍼바이저 승인
3. eBilling 번호 생성 → 고객에게 알림
4. 고객 납부 → 입금 확인
5. DJP 제출 → BPE(전자접수증) 발급

사이드바 → **제출 현황**에서 각 단계의 진행 상태를 실시간으로 확인할 수 있습니다.

## 완료! 매달 반복

이후부터는 매달 Step 6만 반복하면 됩니다.

**월 대시보드** (사이드바 → 세무 관리 → 월 대시보드)에서 모든 고객의 신고 상태를 한눈에 확인하고, 미완성 항목을 클릭해서 바로 처리할 수 있습니다.
